## 本层导读

第 0 层不写技术细节，只解决一个问题：**为什么现在必须学 AI？**

你将理解：
- AI 不是工具升级，是软件范式的代际变迁（Software 1.0 → 2.0 → 3.0）
- 为什么「知识管理」这件事在 LLM 时代被重新定义
- 这套知识库本身，就是新范式的一个实例

学完这层，你会有**动机**——明白为什么后面 21 章值得花 20 小时。

## 🚪 关卡（交错练习）

过了这 3 道题，才进入第 1 层：

1. **场景题**：你的同事说「AI 只是更聪明的搜索」。用 Software 1.0/2.0/3.0 框架反驳他，3 句话内。
2. **费曼题**：向一个 12 岁孩子解释「为什么 vibe coding 会在第 7 天崩盘」。
3. **关联题**：LLM Wiki 和传统 RAG 的本质区别是什么？为什么这个区别在 Agent 时代变得重要？
