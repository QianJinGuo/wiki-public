# SCEI 形式化证明（Formal Proofs of the Self-Calibrating Epistemic Instrument）

> 证明范围的诚实声明：「证明一个理论」只可能指两件事——**内部有效性**（数学骨架的自洽与可证）与**外部有效性**（经验断言可检验）。本页完成前者：把 [[concepts/self-calibrating-epistemic-instrument|理论页]]的五命题与真值衰减检索（TDR）内核写成六个定理并给出证明；后者不可证、只可测，对应 [[queries/prediction-ledger|台账]] #12-#14。理论页持陈述版本，本页持证明版本；推导现场见 [[drafts/wiki-emergent-viewpoints-2026-09-unification-proofs|第十三轮涌现稿]]。

## 0. 公理与形式模型

**公理（模型假设，非定理——假设本身的检验方式见文末边界表）**

- **A1 原子性**：知识内容可分解为 claim 集合 C，每个 claim 有可识别的"被推翻"事件（由库的 claim 级引用与对账纪律操作化）。
- **A2 类条件指数生存**：claim c 所属类 κ(c)，其寿命 X_c 类内 i.i.d. 服从指数分布，失效率 λ_κ；生存函数 S_κ(t) = exp(−λ_κ·t)，半衰期 T½_κ = ln2 / λ_κ。
- **A3 检测敏感度**：推翻事件被库的对账流（台账判定、矛盾解决）以概率 s ∈ (0,1] 检出，s 与寿命独立。
- **A4 测量被动性**：对账行为不改变 λ_κ（经典测量，无观察者效应）。

**观测量**（观察时点 T）：类 κ 的暴露量 Y_κ = Σ_c min(X_c, T − t0(c))（右删失），检出推翻数 D_κ。

**核心恒等式**（定理一与定理三的共同支点）：对 X ~ Exp(λ) 与任意删失窗 τ：

```
P(X ≤ τ) = 1 − e^(−λτ) = λ · E[min(X, τ)]
```

即"单位暴露的期望死亡数"恒等于失效率——这就是"暴露量"这个观测量恰好携带 λ 全部信息的原因，也是"零死亡 + 有限暴露仍能给出置信界"的原因。

## 定理一（自校准一致性）

**陈述**：在 A1–A4 下，删失指数似然恰为 L(λ) ∝ λ^D · e^(−λY)。因此 (i) 极大似然估计 λ̂ = D/Y；(ii) E[D] = s·λ·E[Y]；(iii) Y→∞ 时 λ̂ → s·λ 几乎必然（s=1 时收敛到真值）。**估计量只使用库自身事件流（D 与 Y），不需要任何外部裁判——这就是"自校准"的数学内容，仪器性质（P2+P5）的成立证明。**

**证明**：每个 claim 对似然的贡献——检出死亡（寿命 x）：s·λ·e^(−λx)；右删失（删失于 τ）：e^(−λτ)。全库乘积 = s^D · λ^D · e^(−λ·(Σx+Στ)) = s^D · λ^D · e^(−λY)。对 λ 求导取零得 λ̂ = D/Y；(ii) 由核心恒等式逐 claim 求和；(iii) 对 D/Y 用强大数律（泊松化摄入过程下 D ~ Poisson(sλY) 精确成立）。∎

## 定理二（门控引理·消灭子刻画）

**强形式门控要求**：被证伪页（A=0）无论相似度多高，必须排在**一切**活页（A>0）之后——包括相似度接近零的活页。

**陈述与证明**：

- **(a) 凸组合不可能**：设 F = α·sim + (1−α)·G(S,A)，α > 0，G 有界。被证伪页取 sim=1 得分 ≥ α；而真实知识库的活页池必含衰变类老页（S→0）或低权威活页，且总有相似度任意小的活页，其得分 →0 < α。凸组合永远给被证伪页留下 α·sim 的分数地板，强形式门控在原理上不可实现。∎
- **(b) 乘积形式实现**：F = sim·S·A，A=0 ⟹ 得分恒为 0 < 任何正得分活页。∎
- **(c) 消灭子刻画**：可分离形式 F = f(sim)·g(S)·h(A)（f, g, h 在 (0,1] 上为正）实现门控 **当且仅当 h(0) = 0**——权威槽位上的"消灭子"。必要性：h(0)>0 时取大 sim 的被证伪页与大 S 的活页比较即违门控；充分性：h(0)=0 使被证伪页得分恒 0。∎

**推论**：temporal IR 凸组合路线与 TDR 乘积路线的差异是**种类差异**而非参数差异——前者在原理上无法把"已判定为伪"编码为硬门（第十二轮回溯评测中 partially-falsified 页在乘积下沉底、在凸组合下保有地板的行为差异由此定理保证）。

## 定理三（删失估计引理·三的法则）

**陈述**：D=0、暴露 Y 时，s·λ 的 1−α 置信上界为 −ln(α)/Y；惯例档（α 取 0.05）即 λ < 3/Y，半衰期下界 T½ > ln2·Y/3；敏感度 s < 1 时下界按 s 线性缩水。

**证明**：由定理一的似然，P(D=0 | λ) = e^(−sλY)；集合 {λ : e^(−sλY) ≥ α} = {λ ≤ −ln(α)/(sY)} 是 λ 的 1−α 置信集，反演即得。∎

**库内现状**（测量值，非本页证明对象）：机制类九页总暴露 64 页日、零检出 → 半衰期下界约两周，随暴露量机械收紧；复算口径与工具见 [[concepts/claim-half-life]] 与 `scripts/tdr-retrospective-eval.py --exposure`。

## 定理四（误差域支配）

**设置**：同一知识对象的真页 y 与陈旧页 x，同类 κ，令 ρ = (S_κ(Δt_x)·A_x) / (S_κ(Δt_y)·A_y)——"衰减-权威差"的倒数倍率；判定场景（x 更老且类在衰变，或 x 被权威降权）下 ρ < 1。

**陈述与证明**：

- (i) TDR 把 x 排到 y 之上 **当且仅当** sim_x > sim_y / ρ（相似度差必须超过衰减-权威差的倒数倍）。证明：TDR 得分比 = sim_x·ρ / sim_y，直接变形。∎
- (ii) **TDR 不引入新错误**：ρ < 1 ⟹ {sim_x > sim_y/ρ} ⊊ {sim_x > sim_y}——TDR 错排集是纯相似度错排集的真子集。∎
- (iii) **修复区**：sim_y < sim_x ≤ sim_y/ρ 时纯相似度排错而 TDR 排对；该区间当 ρ→0（让位/证伪判定）时扩张到"无论相似度多高都被压下"。∎

**意义**：第十二轮回溯评测中术语链修复（陈旧让位版从纯相似度第一名被 TDR 压到底部）不是运气——A=0 使 ρ=0，定理四 (iii) 的极限情形，只要真页相似度为正就**必然**排对。

## 定理五（机制类无害性）

**陈述**：若 λ_κ = 0（S ≡ 1）且池内无权威降权（A=1），则 TDR 排序与纯相似度排序完全一致。

**证明**：共同乘法因子 1 不改变序。∎

**意义**：全局手调衰减基线在对照组把机制类页从榜首打到第九名（第十二轮实测），此类"时间误伤"在类条件仪器下**原理上不可能发生**——对照实验的结果是定理五的必然，不是幸巧。全局单一半衰期基线只要跨类失效率不同就必然违反本定理。

## 命题六（反身性适定性）

**陈述**：定标回路 Φ：事件流 → λ̂ →（检索排序、写入门）→ 未来事件流。在 A4 下，回路对**估计量**的不动点就是 s·λ_κ 本身；反馈改变的是库的**构成**（哪些 claim 存在），不是**常数**（claim 死多快）。因此仪器可以改变库"装了什么"，同时保持对"死多快"的一致估计——自我测量是经典测量，无观察者效应。

**论证**：λ̂ 的似然只含类内的 D 与 Y 计数；构成变化（写入门杀掉坏 claim、检索排序改变消费与复查模式）只改变类间混合权重，不进入类内似然。真正要防的循环论证是"用受估计量影响的构成去估计聚合衰减率"——类条件估计 + A4 恰好绕开它；聚合衰减率是混合量的函数，不是常数，不得当常数估（[[concepts/claim-half-life]] 的类条件口径即此命题的操作化）。∎

## 乘积形式的第二独立理由（贝叶斯读法）

定理二证明乘积是**实现门控的最低要求**；本节给出它与信念修正的独立吻合：把 S_κ(Δt) 读作衰减先验、权威判定读作独立证据，则 sim·S·A 正是"该 claim 仍然可信"的后验的因子分解——**乘积 = 先验 × 证据**，其条件独立假设即 A4。于是 P3（检索即信念修正）不是比喻：乘积形式同时是门控可行的（定理二）、贝叶斯正确的（本节）、误差域支配的（定理四）——三条独立理由收敛于同一形式。
