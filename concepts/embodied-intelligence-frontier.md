# 具身智能前沿

> 本页填补知识库在具身智能维度的不足。

## 从语言 Agent 到具身 Agent

语言 Agent 在数字世界中操作 API 和代码，具身 Agent 在物理世界中操作物体和环境。具身智能的核心挑战是感知-行动闭环的实时性和物理世界的不可逆性。

## 关键技术方向

1. **视觉-语言-动作模型**（VLA）：从视觉感知到动作输出的端到端模型
2. **触觉感知**：视觉之外的触觉反馈改写具身智能格局
3. **仿真到现实**（Sim-to-Real）：高保真仿真环境训练，迁移到真实机器人
4. **自改进策略**：NVIDIA ENPIRE 式的机器人策略自改进
5. **大脑-小脑架构**：大模型规划 + 小模型高频执行
