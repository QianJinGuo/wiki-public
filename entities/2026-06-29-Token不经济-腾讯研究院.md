## 摘要

文章提出"token不经济"概念：企业拥抱 AI 却只见账单变长不见收益——微软收回开放仅 6 个月、已成内部最受欢迎辅助开发工具之一的 Claude Code 许可并将员工导向 Copilot CLI；Uber 仅 4 个月耗尽 2026 全年 AI 编程工具预算；Meta 悄然撤下 Tokenmaxxing 排行榜。供给端上，Anthropic 凭编程优势建立分层定价权（Opus $15/$75、Sonnet $3/$15、Haiku $1/$5，后又置入 Mythos Preview $25/$125 超高端分层），ARR 从 2024 年底约 10 亿美元飙升至 2026 年 5 月约 450 亿美元；而经济型 token 市场在需求爆发中默默涨价——Haiku 4.5 较 3.5 上浮 20%，Gemini 2.5 Flash 输出定价较 2.0 翻了 6 倍多，GLM-5 较 GLM-4.7 提价约 67%-100%。^[raw/articles/2026-06-29-Token不经济-腾讯研究院.md]

技术面存在四重结构性浪费：上下文陷阱（ChatDev 框架中代码审查阶段 token 占比达 39.5%）、分词器黑箱（Opus 4.7 更换分词器后企业实测平均膨胀 1.47 倍，同一系统提示词从 5,039 涨至 7,335 tokens）、技能冗余（SWE-Skills-Bench 测试 49 个技能中 79.6% 无通过率提升，平均效用增量仅 1.2 个百分点而 token 开销最高增加 451%）、多 Agent 沟通税与长程任务熵增。需求端的更深层限制是：编程是"通用的特例"——只有它具备编译器式的确定信号反馈和自动后训练闭环，而 Harvey AI 部署于 A&O Shearman 后所有输出仍需律师复核（复核时间几乎等同从头审阅）；物理世界则受 Sim-to-Real Gap 制约（OpenAI Dactyl 灵巧手仿真 13,000 年训练量后仍因鲁棒性不足解散团队）。风险端，产业链风险向中游聚集：上游台积电、英伟达自由现金流分别增长 14.5% 和 58.8%，下游亚马逊 FCF 却下降 76.6%；OpenAI-英伟达-甲骨文的循环融资使算力采购承诺突破 1 万亿美元（年化营收仅 330 亿美元）；弗吉尼亚数据中心容量拍卖价格从 29 美元/MW-天飙升至 444 美元/MW-天，居民电费可能翻倍。解法上，文章主张供给端语义压缩、技能减法（SkillReducer 实现 39% 技能体压缩且质量反升 2.8%）、模型路由与多 Agent 预算硬约束，需求端寻找弱确定性反馈的中间场景，最终回归"用最少 token 把事做成"的 ROI 金标准。^[raw/articles/2026-06-29-Token不经济-腾讯研究院.md]

## 关键要点

- token 不经济是内控不力、token 回报有限、Agent 架构设计缺陷（Skill 重复调用、长程任务内耗、多 Agent 协同成本）多重叠加的结果。
- Anthropic 分层定价形成"能力分层、风险分层、定价分层"三维策略，2026 年 5 月 ARR 约 450 亿美元；OpenAI、Google 仍需以价换量。
- 四项研究证据：代码审查占 ChatDev token 消耗 39.5%；Opus 4.7 分词器致 token 膨胀最高 1.47 倍（图片达 3.01 倍）；79.6% 的软件工程技能无通过率提升；多 Agent 沟通税使超一半 token 花在内部协调与自我纠偏。
- Bain 测算：消化 2030 年新增 200GW 算力需终端每年约 2 万亿美元新增营收，即便算上成本节约仍有约 8000 亿美元缺口。
- 未来企业 AI 治理将以配额、审批、成本归因为基本方式，配给制倒逼更高效的 Agent 架构设计。
