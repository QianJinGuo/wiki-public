## 摘要

文章以 GPT-5.5 在 5 月 5 日下午 5:55 自选时间办庆祝派对、客人由 Codex 从推文回复中挑选的新闻切入，复盘了过去两个月开发者从 Claude Code 向 Codex 迁移的完整过程 ^[raw/articles/2026-05-05-5月5日5点55分-GPT-5-5自己选客人开派对-Codex反超Claude--新智元.md]。导火索是 3 月下旬 Claude Code 的配额危机：Bun 打包二进制中每个 API 请求都对内部 billing sentinel 字符串做替换，破坏了 prompt cache 前缀完整性，未缓存 token 成本是缓存的 10 到 20 倍，开发者用反编译工具比官方更早找到根因 ^[raw/articles/2026-05-05-5月5日5点55分-GPT-5-5自己选客人开派对-Codex反超Claude--新智元.md]。4 月 22 日 Anthropic 又错误地将 Claude Code 踢出 20 美元 Pro 套餐，几小时内在社区怒火中回滚，撬动了"20 美元能用 Opus"的信任共识 ^[raw/articles/2026-05-05-5月5日5点55分-GPT-5-5自己选客人开派对-Codex反超Claude--新智元.md]。文章的关键数据结论是：Codex 反超的不是代码质量而是"更便宜、更快、更不被掐断"——盲测代码质量 Claude Code 仍以 67% 胜率领先，但开发者用量曲线已穿过 50%，Codex 4 月 8 日宣布周活破 300 万，4 月 29 日 Sam Altman 宣称 Codex 正经历"ChatGPT moment" ^[raw/articles/2026-05-05-5月5日5点55分-GPT-5-5自己选客人开派对-Codex反超Claude--新智元.md]。

## 关键要点

- 数字对比：Codex 完成 Express.js 重构用 150 万 token，Claude Code 用 620 万（约 4 倍）；npm 日下载 Codex 4433 万对 Claude Code 44 万（约 100 倍），周下载 1.3 亿对 770 万（约 17 倍），但 Sam Altman 转发时声明数据来源可能不准确
- Claude Code 的领先项：SWE-bench Pro 64.3%（Opus 4.7）对 58.6%（GPT-5.5）；dev.to 盲测 12 轮赢 8 轮；2026 年 2 月年化收入突破 25 亿美元，是历史上最快到 10 亿美元的 AI 编程产品
- 根因技术细节：Claude Code 是 228 MB 的 Bun 二进制；自定义 Bun fork 的 sentinel 字符串替换破坏 prompt cache，--resume/--continue 标志会让整段对话缓存失效
- 4 月 22 日套餐风波：Anthropic 尝试把 Claude Code 绑定到 100/200 美元 Max 套餐，Simon Willison 评论"Anthropic 无意间给 OpenAI 递了一个营销优势"，几小时内回滚
- Codex 产品侧：4 月 16 日更新后已能控制整台电脑、内置浏览器、记住屏幕活动、与 90 多个第三方插件互通；Greg Brockman 2 月 19 日公开宣布从 Emacs 切换到 Codex 桌面
