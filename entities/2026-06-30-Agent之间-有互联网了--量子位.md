## 摘要

量子位报道明略科技开源的 Agent 协作网络 Octo，定位是让人、Agent 和外部工具进入同一套协作系统，口号是 "Agents do. Humans decide."。Octo 用三个核心概念给 Agent 一个组织内的"工位"：Bot（Agent 以数字同事身份加入，有 AgentCard、能力边界和工作履历，可接入 OpenClaw、Hermes、Codex、Claude Code、WorkBuddy 等工具）、Channel/Thread（协作频道与具体事项线程）、Matter（把聊天变成有负责人、交付物、验收标准的可追踪事项）^[raw/articles/2026-06-30-Agent之间-有互联网了--量子位.md]

Octo 定义了六种协作模式——Solo（单人完成）、Roundtable（圆桌讨论）、Critic（独立审核，做审分离）、Pipeline（流水线交接）、Split（分头干再合并）、Swarm（竞选择优），产品形态覆盖 Web App、移动端、浏览器插件与 CLI 四个端。O.C.T.O. 四字母代表 Open（开放可自部署）、Context（上下文流动）、Taste（沉淀人的偏好与判断）、Orchestration（编排），每次协作沉淀 Context、Taste、Skill 三类资产。文章认为这代表 AI 应用正从"个人效率工具"向"组织协作网络"迁移 ^[raw/articles/2026-06-30-Agent之间-有互联网了--量子位.md]

## 关键要点

- Octo 是明略科技开源的可自部署 Agent 协作网络，强调开源与私有化部署，让企业的业务上下文、协作记录、偏好判断沉淀为自有资产。
- 六种协作模式：Solo、Roundtable、Critic、Pipeline、Split、Swarm，分别对应边界清晰小任务、头脑风暴、质量审核、多步顺序任务、大任务拆分并行、创意竞选择优。
- 三个核心概念：Bot（数字同事身份 + AgentCard）、Channel/Thread（协作场所与事项线程）、Matter（含负责人、交付物、验收标准的可交付事项）。
- 四端覆盖：Web App 工作台、移动端（iOS/Android）验收拍板、浏览器插件（在当前页面直接呼出 Agent 并带入上下文）、CLI（开发者终端场景）。
- 与飞书/Slack/钉钉的差异：传统 IM 为人和人设计，Octo 处理 AI 身份管理、AI 任务追踪、AI 协作模式等 Agent 成为工作主体后的新问题。
