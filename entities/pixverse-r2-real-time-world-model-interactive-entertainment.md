# PixVerse R2：实时世界模型在互动娱乐场景的落地实践

## 摘要

PixVerse（爱诗科技）2026 年 1 月推出业内首个实时视频世界模型 R1，8 月以 R2 将其推进为「可持续、稳定运行、真正能玩起来」的世界系统。R2 的改动发生在底层：先用统一的 Omni Causal AR 持续预训练养大生成质量、长程一致性与多模态控制的上限，再用 Real-Time Acceleration 从同一基座蒸馏出实时学生模型，尽量无损地压进可交互延迟区间——由此同时回答实时世界模型如何持续 scaling、以及它如何走出实验室直面用户。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

## 核心要点

- **R1 → R2 是范式跃迁**：R1 用「一句话实时改变画面」证明实时视频世界模型可行；R2 回答它如何持续 scaling，给出「能一直玩下去的世界」。
- **多模态控制揉进同一套体验**：WASD 管「往哪走」，语言/语音管「世界接下来发生什么」，两类输入同时生效且剧情自洽。
- **需求已被线下验证**：万岁山武侠城近 2000 名 NPC、每天上演上千场互动，游客为没走完的任务规划二刷三刷。
- **训练范式重构成两道工序**：旧链路收敛为「养大 Omni Causal AR → 蒸馏实时模型」，中间环节反复迁移带来的层层折损被消除。
- **稳定性可量化**：Error Bank 让长期亮度漂移从 0.201 降到 0.129（约 −35.8%），Block-sparse Attention 稀疏度 90% 以上而画质不退化。

## 深度分析

### 「实时」只是入场券，能玩下去才是门槛

R1 靠实时响应带来变魔术般的新鲜感，但只响应一句 Prompt 撑不起持续体验，很容易玩腻。真正的门槛是一组系统问题：用户与世界怎么对话、多模态输入能否生效、延迟扛不扛得住、世界怎样长时间不翻车不穿帮。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

R2 的内测 case 给出初步解法：潜入游戏中玩家一边用 WASD 躲避追兵，一边用文字改写局面（输入「增加障碍物阻止追兵」即滚出油桶、「开启秘密路线」即出现石门），剧情仍自洽；古风世界里临时「召唤一只老虎坐骑」并骑上赶路，却没打断主流程。关键能力由此显现——**玩家可以跑出剧本，但世界还知道怎么把你接回来**：过去自由来自预制分支，这里主线仍在，主线之间的过程却能临场生成。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

### 训练范式重构：把互相矛盾的需求拆成两道工序

过去链路越拆越细，五六道手续（改自回归、子任务教师模型、少步蒸馏、自生成历史修正）下来，画质、控制与稳定性层层折损，像传话游戏一样走样。R2 收敛为两件事：持续预训练统一的 Omni Causal AR，把生成质量、长程一致性与多模态控制放进同一模型一起养大；再从这已跑稳的大模型直接蒸馏出实时模型（Real-Time Acceleration），让新数据、新任务、新控制信号进同一条主线。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

Omni Causal AR 把文本、参考内容、语音、WASD 收进同一模型，输出时间同步的音视频流并边跑边收新输入；难点恰在「统一」——按键要立刻反馈，剧情指令却描述持续数秒的完整事件，故用 Dynamic Chunk 按语义边界自适应切分（操作切短、事件切长）。蒸馏侧最关键的决定是**起点统一**：教师、学生的初始化与真实自回归推理都从同一 Omni Causal AR 出发，蒸馏便从「重新学习」退化为「少步加速」。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

### 长时程一致性的四类失败与分层防御

自回归世界模型漂移的根源是结构性的：早期一个小错被写进历史，后面每帧都当事实继承，错就滚成漂移——调参解决不了，只能在四个层面各设防线。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

**干净历史与现实历史的落差**：训练读干净真值、推理读带噪自历史，故用 Hybrid Teacher / Diffusion Forcing 掺入带噪历史，再用 Causal Attention Mask 与相对时间编码约束可见的历史范围与位置。**记忆的算力预算**：全记住算力扛不住、裁太狠又丢身份，故分三层——Sink Memory 管角色/场景/世界规则等长期锚点，Rolling History 盯最近动作/姿态/镜头，Object KV Cache 压缩复用对象级历史。**错误的复利**：Error Bank 像错题本，把代表性错误历史按比例回放，让模型练习从出错状态里把自己捞回来。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

加速靠三手段分管三块成本：DDMD with Adversarial Regularization 把条件对齐、分布匹配、对抗正则分开构造再汇入同一学生模型；Block-sparse Attention 只精算关键连接（稀疏度 90% 以上、质量无明显退化）；Pyramid Ultra-few-step Distillation 先低分辨率定结构、再用极少高分辨率步骤补细节。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

### 为什么「世界模型 + 互动娱乐」是王炸

互动式娱乐的强大早已被岩田聪点破——他二十多年前就指出，「即便过了十年甚至十五年，玩过的游戏仍会留在记忆之中」，而小说、电影常只记得当时感动过，差别在于游戏是亲身操作、有输入有反馈、每次体验都可能不同。但过去游戏绝大多数可能性都需提前制作，分支再密也只是在写好的剧本里挑一条路，通关之后世界就被掏空。世界模型加入后边界有机会外推：创作者先定义世界观、角色、规则、视觉风格与核心剧情，再让部分具体内容在互动发生的那一刻生成。R2 的世界探索、剧情互动、实时角色三方向恰对应互动娱乐三要素（行动的空间、继续的叙事、能回应人的角色），当它们由同一实时世界模型驱动，游戏、影视、数字人与文旅的边界也会随之模糊。^[raw/articles/都在问世界模型怎么落地pixverse把答案做成了好玩.md]

## 实践启示

1. **先定义「能玩下去」的最低标准**：成败不只在单帧画质，更在延迟、输入生效、新剧情接续与长时稳定；应把长序列漂移率当一等指标。
2. **统一基座优先于链路拼接**：优先复用统一的多模态因果基座，再从中蒸馏实时学生模型，让蒸馏退化为少步加速而非重新学习。
3. **主动暴露于「不完美的自己」**：训练掺入带噪历史并约束注意力可见范围与时间编码；维护「错题本」式样本库并按比例回放。
4. **记忆按时间尺度分层**：长期锚点与短程连续分机制管理，在固定算力预算下同时保住「同一个世界」与「顺畅衔接」。
5. **用线下已验证的需求选场景**：万岁山近 2000 NPC、日均上千场互动、游客自发二刷说明需求真实；首个落地点宜选这类受制于内容预制成本的方向。
