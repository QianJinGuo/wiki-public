## 摘要

文章梳理 Karpathy 在 Sequoia AI Ascent 2026 炉边对话及后续长帖中提出的"Software 3.0"框架：Software 1.0 是人写代码（作者），2.0 是用数据训练神经网络（教练，2017 年他提出"训练即编程、数据集就是源代码"），3.0 则是通过 prompt、上下文、Agent、工具、记忆和验证来编程（指挥官）——LLM 成了新型计算解释器，prompt 就是源代码，context window 成为新的编程界面。Sequoia 合伙人 Stephanie Zhan 用一句话概括对话核心："Vibe Coding 抬高的是地板，Agentic Engineering 抬高的是天花板"——前者让不懂编程的人能用自然语言做出可用应用，后者要求专业开发者设计 Agent 生成、编码、测试、互查的整套系统而不牺牲安全与可维护性。Karpathy 自述 2025 年 12 月经历了从自己写 80% 代码到 Agent 写 80% 的"翻转"，甚至患上每天对 Agent 说话 16 小时的"AI 精神病"。^[raw/articles/2026-05-01-软件-3-0-时代来临-AGI-Hunt.md]

两个关键论断值得注意。其一是"传统软件自动化的是你能规格化的东西，AI 自动化的是你能验证的东西"：模型能重构十万行代码库、发现零日漏洞，却会说"你的车在 50 米外的洗车店，建议步行过去"——这种"锯齿状智能"不仅与可验证性有关，还与经济学有关，TAM 决定实验室 RL 训练覆盖哪些领域；创业机会在于找到可构造验证环境但尚未被大实验室 RL 覆盖的领域。其二是他自己的 MenuGen 项目：拍照菜单直接交给 Gemini 在原图上叠加菜品图片，传统 OCR→NLP→图像搜索→前端的中间层整个变得多余——"有些应用不是被做得更快了，是被模型原生能力直接吞掉了"。他还主张未来软件应为 Agent 重写而完全不考虑人类用户（用 .md 文件替代 .sh 安装脚本，"LLM 就是一个高级的英文解释器"），同时强调系统规格设计、概念理解和品味是人的不可外包之处——"你可以外包你的思考，但不能外包你的理解"。^[raw/articles/2026-05-01-软件-3-0-时代来临-AGI-Hunt.md]

## 关键要点

- Software 2.0 文章写于 2017 年 11 月 Karpathy 还在 Tesla 做 Autopilot 时，他自认写得太早、没预见到 LLM。
- Harness 概念最早由 HashiCorp 联创 Mitchell Hashimoto 于 2026 年 2 月提出：每当 Agent 犯一个错，就工程化一个方案让它不再犯。
- Anthropic 的长时运行 Agent 方案：搭建环境、创建进度文件（claude-progress.txt）、建立基准 commit，每个新 context window 先读 git log 和进度文件再继续。
- 三代软件中人类角色从作者→教练→指挥官（how→show→what），失去执行细节控制、获得更高层次杠杆；瓶颈从 GPU 空闲变成 token 没花完。
- Karpathy 的远景展望是"全神经计算"：绝大多数计算由神经网络处理，传统 CPU 降级为协处理器。
