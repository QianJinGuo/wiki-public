# LoD：从LVLM逐层内部激活学习未见攻击检测（EMNLP'26）

中国人民大学与阿里巴巴联合提出的 LoD（Learning to Detect）框架，把大视觉语言模型（LVLM）的越狱检测从前置规则/攻击数据驱动，转向**从模型内部安全表征学习通用安全模式**——不依赖任何越狱攻击样本，也不用手工启发式规则，而是把"未见攻击"识别为偏离安全分布的异常。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

## 问题动机

LVLM 把语言理解扩展到图像等多模态输入，同时引入更隐蔽的攻击面：细微图像扰动、视觉文字或跨模态提示可能绕过安全对齐，让模型回答本应拒绝的有害问题。已有攻击（如 AdvBench 上）甚至能诱导对齐模型回答 **96%** 的不安全问题。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

现有检测器面临两难：
- 学习式检测方法可对已见攻击取得高准确率，但容易"记住攻击特征"，面对新攻击泛化受限。
- 免训练方法靠人工规则/拒答词/梯度特征规避攻击数据依赖，但复杂场景精度不足，且有额外计算开销。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

## 核心方法：MSCAV + SPAE

LoD 分表示学习与攻击分类两个模块，从逐层内部激活提炼安全信号：

1. **提取逐层内部激活**：读取 LVLM 各层最后一个输入 token 的隐藏状态 eˡ。
2. **MSCAV（安全感知方向学习）**：每层训练轻量线性分类器 Cˡ，用安全输入与普通有害输入学习安全相关方向，分类器输出的不安全概率构成逐层安全表征；验证准确率 P0=0.9 的层进入安全感知层集合 Ls，过滤任务无关噪声。
3. **SPAE（安全流形重构）**：三层全连接编码器 + 对称解码器，仅用安全输入的安全表征训练；编码器压缩跨层安全模式，解码器重建。安全输入位于学到的安全流形附近，通常能准确重构。
4. **重构误差识别未见攻击**：测试时计算 SPAE 重构误差 δ，低误差表示接近安全分布，高误差表示内部安全模式异常，δ 超阈值 τ 标记为攻击。在线检测不需要反向传播，也不修改自回归解码。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

关键机制：安全表征 Ŝr = f_dec(f_enc(Sr))；δ = ‖Ŝr − Sr‖²。MSCAV 负责"提纯安全信号"，SPAE 负责"度量对安全模式的偏离"。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

## 实验结果

模型覆盖 LLaVA-1.6-vicuna-7B、Qwen2.5-VL-7B-Instruct、CogVLM-chat-v1.1；攻击覆盖 4 类提示操纵（FC-Attack、JOOD、HADES、MML）与 2 类对抗扰动（VAJM、UMK）；基线为 MirrorCheck、CIDER、JailGuard、GradSafe、HiddenDetect。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

- 三种 LVLM 平均 AUROC 达 **0.9820 / 0.9838 / 0.9705**，整体接近 1。
- 相对最强基线，LLaVA/Qwen2.5-VL/CogVLM 平均 AUROC 提升 **19.32% / 4.50% / 17.11%**。
- 最差攻击场景提升显著（LLaVA 相对增益 **170.4%**），不只是拉平均分。
- 单输入检测时间 **0.25–0.62 秒**，相对最佳基线最高降低 **62.7%**。

消融显示移除 MSCAV 后性能下降最明显（安全聚焦的内部表征是检测关键）；移除 SPAE 后平均 AUROC 降至约 0.857–0.8x。代码已开源，可在不同 LVLM 上一次性离线适配后用于在线检测。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

## 意义与定位

LoD 的范式转向是：**学习"安全输入在模型内部应该呈现什么模式"，而非"某一种攻击长什么样"**。这使其天然具备对未见攻击的泛化能力，同时保持在线检测的低延迟。属于异常检测式 AI 安全防线，与规则/攻防样本驱动的方法互补。^[raw/articles/0.25秒识破未见攻击-lod-lvlm-jailbreak-detection-emnlp2026.md]

## 深度分析

### 范式转向：单类建模取代二类判别

传统学习式检测把越狱当作"第二类"样本问题，天然受制于训练集里出现过的攻击形态；攻击一旦换皮，检测器就退化。LoD 的做法在问题定义层面就绕开了这个死结：只用安全输入与普通有害输入，学习"安全状态在模型内部该长什么样"，把检测重构为对安全流形偏离程度的单类异常度量。其成立的前提假设是——安全模式的内部表征比具体攻击手法更稳定，因为无论伪装如何翻新，攻击最终都要把模型推离正常的安全工作区。这解释了为何它对六类完全未见过的攻击（提示操纵与对抗扰动两个家族）依然保持接近 1 的 AUROC。

### 三类输入的区分是整个设计的地基

原文刻意区分了安全输入、普通有害输入、攻击输入三种情形，而 MSCAV 的训练只涉及前两类——攻击样本直到测试阶段才出现。这个区分让逐层线性分类器学到的方向对应"安全语义 vs 危险意图"的本质差异，而非某种伪装技巧的表层特征；伪装层（视觉编码、跨模态提示、对抗扰动）因此在安全表征中反而显得异质，被重构误差自然捕捉。换句话说，攻击越是依赖伪装，就越偏离安全流形——攻击的复杂度成了检测信号而非障碍。

### 提纯与度量解耦的两级流水线

MSCAV 与 SPAE 的分工可理解为"信号提纯 + 分布度量"：前者在每层训练轻量线性分类器，把语义、视觉结构、情感等混杂的高维激活压缩为逐层不安全概率序列，并用 P0=0.9 的验证准确率门槛筛掉任务无关层；后者在提纯后的表征上仅用安全样本训练编码器-解码器，把跨层安全模式压成可比较的重构误差 δ。消融证实两级缺一不可：去掉 MSCAV 性能下降最明显，说明安全聚焦的表征是根本；去掉 SPAE 后 AUROC 降至约 0.857–0.875，说明高维表征本身还不足以直接转换为可靠的异常分数。

### 工程可行性与防线前移

在线阶段无需反向传播、不侵入自回归解码循环，单输入检测 0.25–0.62 秒；一次性离线适配只需约 12 秒（MSCAV）+ 2 秒（SPAE），且代码开源、跨三种异构 LVLM 均验证有效。低开销 + 免攻击数据意味着该方案可以部署在生成之前，把越狱防线从"事后审查输出"前移到"事前拦截输入"，这在多模态入口日益增多的生产环境里比检测准确率本身更有部署价值。

### 已知边界与部署代价

MML 是最具挑战性的边界场景，LoD 通常只能保持第二名；在 FPR=0.01 的严格低误报约束下，三种模型的平均 TPR 分化明显（0.487–0.764）。这说明阈值 τ 的选取必须与业务的风险容忍度联动：安全关键的场景宁可惜杀，流量敏感的场景则需接受一定的漏检。此外稳健性实验（HarmBench 替换 AdvBench、向 SPAE 加入有害表征无一致收益）反向印证了单类学习设计的自洽性。

## 实践启示

1. **优先考虑"学安全分布"而非"学攻击特征"的检测方案**：当威胁模型以未知攻击为主时，单类异常检测（如 LoD 的 SPAE 重构误差）比收集攻击样本训练二分类器更抗过期，且省去持续维护攻击数据集的成本。
2. **检测信号优先从内部激活中找，而非输出侧规则**：逐层激活携带的安全信号在输出文本层面可能已被伪装掩盖；如果业务已部署 LVLM，hook 中间层隐藏状态 + 轻量线性探针是低成本的第一步尝试。
3. **特征提纯是异常检测的前提，不能拿原始激活直接算距离**：先用分类器验证准确率（如 P0≥0.9）筛选安全相关层，再做流形建模——跳过这一步大概率会把语义/视觉噪声误算成异常。
4. **把检测放在生成循环之外、回答之前**：LoD 式在线推理无反向传播且耗时亚秒级，适合作为前置网关；相比事后对输出做安全审查，事前拦截能直接避免有害内容生成。
5. **上线前用最差场景而非平均指标做验收**：平均 AUROC 接近 1 不代表安全，应按"固定低误报率下的 TPR"和最薄弱攻击类型（如多模态边界场景）设定门槛，并据此选择阈值 τ。
