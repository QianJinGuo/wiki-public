## 摘要

腾讯技术工程公众号发布腾讯系统级 AI Agent 产品 Marvis（马维斯）的完整上手实测，核心定位是"把聊天窗口往电脑系统里推进一层"——让 AI 直接理解你的电脑（读文件、找图片、看文档、调用应用、系统设置、手机远程接管），从"你操作电脑再问 AI"变成"你把目标告诉 AI，让它去操作电脑"。产品形态为电脑端（Windows/macOS，微信或 QQ 登录）+ 手机端（App Store 搜索 Marvis），背后是多 Agent 协作小队：主 Agent 听懂需求，File Agent 管文件、Computer Agent 管系统、App Agent 管应用、Browser Agent 管网页、Search Agent 管搜索。作者实测 6 个任务：iPhone 远程连接电脑（含远程桌面直接操控）、语义搜索找"记不清名字"的文件、从直播数据表生成结构化周报、检查电脑卡顿原因、跨应用收集 5 个 Agent 产品信息整理成表格、设置每天下午 6 点的定时 AI 资讯收集任务 ^[raw/articles/2026-06-24-从0到1带你速通-Marvis马维斯-腾讯技术工程.md]

关键设置与模式：文件权限建议先建测试文件夹最小授权；连接手机支持微信（仅文字交互）与手机 App 扫码（可远程操控电脑桌面）两种方式，且支持单部手机连接多台电脑作为文件中转站；AI 模式分效率模式（云端大模型，能力强）和本地模式（本地部署模型，隐私优先，适合财务/法务/合同等敏感材料，硬件门槛更高）。文章总结 Marvis 的价值不在单项能力最强，而在把电脑文件、系统设置、应用操作、网页搜索、手机远控、多端协同、本地隐私模式、定时任务揉进一个国内用户熟悉的交付方式里，适合文件混乱者、日常办公者、远程处理电脑事务者和不想折腾工作流的普通用户——"Agent 真正进入普通人生活，是从找文件、整理截图、远程取文件这些润物细无声的小事开始的" ^[raw/articles/2026-06-24-从0到1带你速通-Marvis马维斯-腾讯技术工程.md]

## 关键要点

- 多 Agent 分工：主 Agent 负责理解需求与派活，File/Computer/App/Browser/Search 五个专职 Agent 分别负责文件、系统、应用、网页、搜索。
- 语义找文件实测：从杂乱截图文件夹找 ima copilot 宣传封面，Agent 进行三批次递进收窄检索，靠图片内容理解而非文件名关键词匹配。
- 两个 AI 模式：效率模式连云端大模型；本地模式连本地部署模型，强调隐私，适合处理高敏感信息。
- 系统级 Agent 的安全设计原则：先诊断、再解释、再给方案，最后由用户确认哪些执行——"最重要的不是能不能操作，而是该不该操作"。
- 定时任务限制：电脑关机、休眠或退出客户端时任务不会执行；自动任务适合每天盯资讯等内容运营场景。
