1. # 智能问数Agent--数据智能体-火山引擎 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
**智能分析Agent是一款基于AI深度思考与大数据分析的专家顾问**。 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
2. 分析Agent包含智能问数Agent和深度研究Agent，**智能问数Agent**作为一款灵活配置的智能问数工具，可以让用户以简单对话的方式更准确地查询业务数据，支持多数据集查询、语义模型解析、业务知识调用、问题推荐与收藏、个性化推送、多轮交互式问数，以及归因分析等，能够全方位满足用户多样化的数据查询需求。 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
3. ## 功能概述 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
智能分析 Agent 的智能问数 Agent 功能可通过自然语言对话精准解析用户意图，实现多数据集协同查询与深度归因分析，辅以个性化推荐、多轮交互等功能，为用户提供高效、精准、统一的数据查询服务。 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
4. ## 具体功能 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
- **推荐问题**：提前将团队大多数用户关心的问题内置到智能体，其他用户点击问题即可快速查询。
5. - **收藏问题**：将自己常问的问题收藏起来，下次直接点击即可快速查询。 ^[raw/articles/volcengine-data-agent-intelligent-query-agent.md]
