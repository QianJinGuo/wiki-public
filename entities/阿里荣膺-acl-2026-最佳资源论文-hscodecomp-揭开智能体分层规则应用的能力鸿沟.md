## 深度分析

### Level 3：从「读懂网页」到「用对规则」的知识复杂度跃迁

论文把 Agent 所需的知识复杂度切成递进的三层：Level 1 是开放域网络数据的理解与推理（BrowseComp、GAIA 一类），Level 2 是数据库、知识图谱等结构化数据的精确利用（MedBrowseComp、FinSearchComp 一类），Level 3 才是本文焦点——在前两者之上，逐层精准应用人类专家撰写的层级规则，而这恰好是现有评测体系的一块空白^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:91-97]。HS Code 之所以被选为 Level 3 的代表性载体，在于它是支撑全球约 26 万亿美元贸易的「数字身份证」，申报错误轻则多缴关税、重则触发合规风险^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:46]。更关键的判断是：这类分层规则应用并非海关独有，ICD-10 医疗编码、法律合规、税务审计等垂类共享几乎同构的规则树，因此基准揭示的能力边界具备跨垂类迁移价值^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:117-121]。

### 鸿沟从何而来：级联错误、语义模糊与规则耦合

最强的 Agent 在 10 位编码上只有约 49.4%，而从业十年的关务专家可达 95%——接近腰斩的差距^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:63]。论文将鸿沟归因于分层规则的三个固有特性：其一是层级深且一步错步步错，上层把硅胶误归入橡胶这样的判错会沿规则树级联放大，后续每一层都建立在错误前提上，几乎无从纠偏；其二是规则里充斥「除……以外」「其他」「主要用于」这类语义边界模糊的自然语言限定，高度依赖上下文；其三是规则间充满例外条款与交叉引用，某个品目能否成立往往取决于另一条注释是否被触发^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:104-111]。任务本身也不是一次性分类，而是多步「检索—推理—回溯」循环：Agent 需在噪声商品档案上抽取属性、检索候选规则、核对例外与交叉引用，必要时还要去历史裁定库找先例佐证^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:85]。

### Test-Time Scaling 为何失效：同源错误与推理漂移

「多算几次总会更好」的直觉在这个基准上被证伪。多数投票（Voting@K，K 从 1 增到 16）几乎不带来提升，因为 Agent 无法区分正确路径与「自信的错误」，投票只是在同源错误里挑众数；自我反思的提升同样微弱，模型既会纠错也会把原本正确的答案改错，更像盲目重试而非有效反思^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:225-229]。更有意思的是「推理漂移」现象：强迫模型增大 reasoning effort，GPT-5 的 10 位准确率反而从 40.82% 一路跌到 35.44%——当有价值的信息藏在领域知识与规则里时，缺乏准确工具反馈的「自由发挥」会让 Agent 幻觉出并不存在的约束、误读模糊描述^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:236-242]。典型样例是为强行归类一双女鞋而编造「鞋面表面积超 90% 且无围条」等不存在属性，同时忽略「价格大于 12 美元」的真实规则。

### 什么才真正有效：规则检索、判例库与 Harness 的增益排序

评测覆盖 28 个最先进系统（含 GPT-5.5、Claude-Opus-4.8、GLM-5.2 等模型与多个开源/闭源 Agent 框架）^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:183]，消融结果给出清晰的有效性排序：地基是把裸模型包进能检索并应用最新规则的 Agent 框架（6 个 GPT-5 骨干系统平均从 28.96% 抬到 37.42%，+8.5pt）——且规则不是塞进上下文就行，必须让 Agent 主动检索、按优先级动态裁决、逐层套用；其次是 CROSS 历史裁定库，三个骨干模型接入后 10 位准确率无一例外大幅提升（GLM-5.2 +9.65、DeepSeek-V4-Pro +7.76、Qwen3.7-Max +5.38），相当于配了一本「判例词典」；视觉信息只是边际增益，且高度依赖骨干的视觉能力（GPT-5 +4.11，Claude-4-Sonnet 仅 +0.95，GPT-4o 几乎不动）^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:256-260]。另一侧证据同样有力：在 6k 专家标注数据上做 SFT + Agentic RL 也只能把 Qwen Agent 提到 65%，说明层级规则利用是结构性瓶颈，堆数据、换大模型都绕不过去^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:195]。难度的天然性也由数据侧佐证：最难样本集中在 Novelty & Special Use（占比仅 1.3%）、Men's Clothing（2.2%）等长尾类目，绝大多数品类平均准确率不足 25%——越是非标描述、数据越稀疏，规则应用越容易崩塌^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:275-282]。

## 实践启示

1. **评估垂类 Agent 时优先测「分层规则应用」，别只刷开放域基准。** BrowseComp/GAIA 上的高分掩盖不了 Level 3 能力缺口；若业务涉及法律、医疗、税务、关务等规则树任务，应按 Level 3 标尺（多级 Exact Match）单独评测^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:91-97]。

2. **把预算花在「检索与判例库」上，而不是推理算力上。** 这是一个「规则/知识中心」而非「检索算力中心」的任务：接入历史判例库（类比 CROSS）带来 +5～10pt 的稳定增益，而 Test-Time Scaling（投票、自反思、加深推理）要么无效、要么触发推理漂移^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:248-250]。

3. **Agent Harness 是必需项，且规则不能「塞进上下文」了事。** 裸模型到带工具框架平均 +8.5pt；关键设计是让 Agent 主动检索规则、按优先级动态裁决、逐层套用，并在判错时支持回溯——这也是下一步能力建设的明确方向^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:256-258]。

4. **警惕推理漂移：在规则密集型任务里抑制「自由发挥」。** 增大 reasoning effort 反而降分的根源是幻觉出虚构约束、误读模糊限定；工程上应把推理锚定在检索到的规则与判例之上，对无工具反馈的长链自由推理保持克制^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:236-242]。

5. **构建专业评测集要走专家标注闭环，而不是众包或 LLM 生成。** HSCodeComp 用 26 位平均从业 5 年以上的关务专家、六步「双人独立标注—高级仲裁—抽样复核」流程，分歧率压到约 2%；632 样本经 bootstrap 95% 置信区间验证已达统计平衡，继续扩样收益微乎其微^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:148-160]。

6. **SFT + Agentic RL 有上限，别指望 Scaling 路线自动解决问题。** 6k 专家数据训练后也只到 65%，距人类专家 95% 仍差近 30pt；对分层规则类业务，应把「错误回溯、规则优先级动态判定、推理锚定外部知识」列为明确的优化目标，而非单纯扩大数据或模型规模^[raw/articles/阿里荣膺-acl-2026-最佳资源论文-hscodecomp-揭开智能体分层规则应用的能力鸿沟.md:298-302]。
