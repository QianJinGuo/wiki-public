## 摘要

百度 Geek说 公众号记录前端研发工程师与 AI 组队开发 Chrome 插件 Design.md Token Exporter（一键把网页设计系统提取成结构化 DESIGN.md，已上架 Chrome 应用商店）的全过程与产品取舍思考。作者的"临时产品小队"分工明确：ChatGPT 讨论产品方向、把模糊的审美概念梳理成功能逻辑，Codex 当主力程序员实现代码/补类型/跑测试打包，Gemini 做体验顾问挑战交互细节。起因是一位设计师朋友的提问——为什么她用大模型写网页永远是"AI 蓝紫风"（高饱和度、霓虹渐变、浮夸阴影），而作者把手稿风 DESIGN.md 粘给大模型就能出质感页面，由此意识到核心问题是"不知道怎么把喜欢的风格稳定转化为能交给大模型的输入" ^[raw/articles/2026-06-22-当代码越来越便宜-什么在变贵--百度Geek说.md]

文章的核心论点是：技术平权降低了做产品的门槛，却没有自动赠送产品判断——"当代码越来越便宜，取舍就越来越贵"。两个典型决策：一是彻底砍掉预览面板（Preview Tab）——分析 Claude 极度内敛的页面时预览跑偏成高饱和蓝色 SaaS 卡片，大模型兴奋地给出复杂修补方案，但作者基于"信任债务"（Trust Debt）判断预览不准会让用户连底层 tokens 提取都不信任，删除后侧边栏打包体积从 80KB 降到 50KB；二是面对 Chrome MV3 activeTab 权限机制限制（侧边栏按钮点击不算授权手势导致报错），拒绝大模型建议的 contextMenus/commands 等新增权限方案，改为在边界内优化错误提示与状态流转（稳定状态栏、多态错误卡片、保护历史结果、lucide-react 图标替换 Emoji、固定按钮宽度 w-40）。结论：Vibe Coding 的终点是把人类的审美、经验沉淀和产品边界变成可交给大模型的可执行上下文，"决定不做些什么"的判断才是人类留给产品最独特的锚点 ^[raw/articles/2026-06-22-当代码越来越便宜-什么在变贵--百度Geek说.md]

## 关键要点

- Design.md Token Exporter：把网页设计系统（色彩、字形、圆角、间距）一键提取成结构化 DESIGN.md 的 Chrome 插件，解决"AI 蓝紫风"审美转化问题。
- 三模型分工：ChatGPT（产品方向脑暴）、Codex（主力编码、测试、打包、发布前审计）、Gemini（体验顾问挑交互细节）。
- 信任债务决策：预览面板渲染不准时用户会连带不信任底层 tokens 提取；删掉 Preview 后打包体积 80KB → 50KB。
- 权限克制：不新增任何 Manifest 权限（拒绝 contextMenus、commands 方案以避免安装信任门槛和商店审核延期），用纯前端的容错和状态流转逻辑解决 activeTab 报错。
- 核心观点：AI 是拥有无限精力的匠人，不加控制会用代码盖出"由伪需求堆积而成的庞大废墟"；产品判断（做什么、不做什么）是技术平权时代真正稀缺的能力。
