# ICML 2026 | 南大SAME稳住MoE，缓解多模态持续微调双重遗忘

## 摘要

多模态大语言模型在持续指令微调（MCIT）中需要不断学习新任务、新领域和新回答格式，而 MoE 与 LoRA 结合的稀疏专家结构并不能天然避免遗忘。南大 LAMDA 团队提出的 SAME（Stabilized Mixture-of-Experts）通过诊断实验把 MoE-based MCIT 的遗忘拆解为路由漂移与专家漂移两个来源，并分别用谱感知路由、曲率感知缩放和自适应专家激活三个模块加以稳定。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md] 方法在 TriGap、CoIN、UCIT 三个基准上取得领先准确率，同时降低了训练时间与显存开销。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]

## 核心要点

- **双重遗忘可拆解验证**：路由漂移指旧任务样本在后续训练后被路由到不同专家；专家漂移指即便固定专家、只在 Task 1 数据上重训路由器，旧任务准确率也无法恢复，说明专家功能本身已被新任务改写。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **谱感知路由**：不存储旧样本，为每个含 MoE 的层维护路由器输入的历史协方差，SVD 分解出高能/低能子空间，在高能方向（历史输入常出现的方向）保守缩放更新，低能方向承担新任务适应。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **曲率感知缩放**：把专家功能退化定义为历史输入分布上的期望输出变化，允许"预算内"自由学习，超出阈值才惩罚，用协方差诱导的 Riemannian 预条件实现低开销专家更新。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **自适应专家激活**：训练当前任务时临时冻结"当前利用率低但历史重要性高"的专家，跳过其前向与反向传播；推理阶段全部恢复，不永久减少模型容量。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **TriGap 新基准**：10 个异质任务（文档、图表、信息图、化学、遥感、科学问答等），数据规模 10K–40K 不等，比 CoIN/UCIT 的短序列更能放大路由漂移与专家漂移。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **主结果**：TriGap 平均准确率 46.53%（MoE-LoRA 44.45%），CoIN 66.82%（最强基线 HiDe-LLaVA 63.95%），UCIT 67.12%（ModalPrompt 65.52%）。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]
- **效率收益**：自适应冻结平均每任务节省 32.1 分钟训练时间、约 2.3K MiB/GPU 显存，Task 4/Task 8 分别省 50/58 分钟，任务序列越长收益越大。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]

## 深度分析

### 双重遗忘：MoE 在 MCIT 中失效的真正机制

直觉上 MoE 很适合持续学习——不同任务激活不同专家，天然减少参数冲突。但论文的诊断实验否定了这个假设。第一层证据是路由漂移：训练完 Task 1 后保存其测试样本的专家激活分布，每学一个新任务重新测量一次，发现分布随训练推进持续偏离初始状态，旧样本依赖的专家组合不再稳定。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md] 第二层证据更关键：固定后续阶段的专家快照，只在 Task 1 数据上重新训练路由器——在这种"路由已修好"的有利设置下，Task 1 准确率仍无法回到最初水平。这说明遗忘有两个独立来源，只修路由器救不回来，专家权重本身在历史重要方向上被新任务梯度覆盖。这一拆解直接决定了 SAME 的模块设计：两个漂移来源各配一个稳定化模块，再加一个效率模块。

### 谱感知路由与曲率感知缩放：不存旧数据的双路稳定化

两个模块共享一个关键设计约束：不回放旧任务数据，只维护统计量。谱感知路由对路由器输入做增量协方差递推，压缩进主要奇异方向（能量阈值决定保留数），路由器梯度被分解到高能/低能子空间分别缩放——高能方向更可能影响历史输入的路由行为，更新更保守；低能方向保留可塑性。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md] 曲率感知缩放则处理专家本身：专家权重的一次更新如果落在历史任务频繁访问的输入方向上，就会破坏旧能力，因此用同一份历史输入协方差诱导 Riemannian 缩放（低秩 SVD + 阻尼伪逆实现），限制专家在历史重要方向上的输出变化，历史不敏感方向保持可塑。值得注意其约束形式是"有预算的"：影响低于阈值时完全自由，超预算才惩罚——这是持续性学习里比硬冻结更合理的稳定性-可塑性折中。实验上两者各自可验证：谱感知路由使 Task 1 样本的路由分布偏移显著减小；开关曲率感知缩放的对照显示，加入后重训路由器可恢复的 Task 1 准确率在 Task 5–8 等强干扰阶段明显更高。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md]

### 自适应专家激活：训练期保护罩与效率红利

传统 MoE 在 token 级激活专家，持续学习中一个任务的梯度会散落到许多专家上，即便某专家对当前任务贡献极小，只要偶尔被路由到就可能被改写。SAME 的冻结判据是两个信号的组合：当前任务利用率（路由权重运行均值）与历史重要性（AGOP 思想的轻量代理，路由权重加权输入能量），两者归一化后构成激活分数——只冻结"当前不用但历史关键"的专家。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md] 这比单纯按活跃度冻结更合理：某些低活跃专家可能只是当前任务用不到，却承载旧任务核心功能。冻结只发生在训练阶段，推理时所有专家可选，容量无损。副产品是效率：被冻结专家完全跳过前向/反向，平均每任务省 32.1 分钟和 2.3K MiB/GPU，且后期任务积累的历史重要专家更多，节省更明显——稳定性机制同时降低了开销，而非以额外计算换取稳定。

### 实验证据：从准确率到格式保持的完整链条

主结果之外，论文的格式诱导遗忘分析最有洞察力：CoIN 的 ScienceQA 要求大写选项输出（如"A"），学 TextVQA 后基线倾向输出小写"a"——语义正确却因格式被判错，Task 2 后基线有 70.6% 的语义正确预测因大小写格式判错，且准确率呈"下降-反弹"震荡（反弹可能只是后续任务格式把模型推回去，不代表语义恢复）。^[raw/articles/icml-2026-南大same稳住moe缓解多模态持续微调双重遗忘.md] SAME 显著降低了这一问题，说明其稳定化保护的是任务行为协议而不只是抽象语义。定性结果与之互补：GQA 样本在 Task 4 后基线与 SAME 都答对"Lady"，到 Task 8 基线漂移成"man"而 SAME 保持不变。TriGap 上的表现也说明了方法的适用边界：SAME 并非每个单项任务都第一，收益集中在长序列、多领域、不均衡数据流下的整体平均稳定性——这与其机制定位（抑制漂移）一致。

## 实践启示

1. 在 MoE-LoRA 上做持续微调前，先用论文的两组诊断实验测自己的路由漂移与专家漂移基线：固定专家重训路由器若无法恢复旧任务性能，问题在专家而非路由，调路由器没有用。
2. "历史协方差 + 谱分解缩放"是不存旧数据的遗忘抑制通用模式，同样适用于路由器之外的连续训练模块；相比经验回放，它无隐私/存储成本，代价是协方差统计的实现与数值稳定（阻尼伪逆不可省）。
3. 稳定性约束优先选"预算式"（阈值内自由、超限惩罚）而非硬冻结——后者会牺牲新任务可塑性，前者保留了适应空间。
4. 冻结低活跃专家前先看历史重要性：双信号判据（当前利用率 × 历史贡献）避免误冻旧任务核心专家；冻结只放训练期，推理保持全容量。
5. 评测持续微调时把输出格式漂移单独计入指标：语义正确但格式不符会被判错，"准确率下降-反弹"曲线可能掩盖真实的能力恢复情况。
6. 短序列基准（CoIN/UCIT）可能低估漂移问题；长序列、异质域、不均衡数据流的 TriGap 式设置更能暴露真实部署中的稳定性缺陷。
