# 强化学习的进化：从PPO到MaxRL，LLM推理训练的算法演进史

## 摘要

本文是机器之心对 Alexander Weers 博客文章《RL for LLMs》的编译，系统梳理了 2024 至 2026 年面向 LLM 推理能力训练的强化学习算法演进：从 REINFORCE、PPO 等经典策略梯度方法讲起，经由 GRPO 的「去 critic」改造，延伸到 DAPO、Dr. GRPO、RLOO、CISPO、DPPO、ScaleRL、MaxRL 等一系列变体与反思。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

整理这条脉络的价值在于：绝大多数新方法只改动了目标函数中几处看似无害的归一化、裁剪边界或基线选择，而这些改动却直接决定了训练是否稳定、推理链是否会失控变长。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

## 核心要点

- **PPO 是第一代基石，也是第一代包袱**：源自雅达利游戏与机器人等传统 RL 场景，成功适配进 RLHF，是 GPT-3 → InstructGPT 的关键；但完整形态（可训练策略、推演策略、参考策略、价值模型）需四个大组件同时驻留显存。
- **第二代算法围绕「推理能力」爆炸式涌现**：目标从「对齐人类偏好」转为「提升推理」，短期内大量变体出现，多数仅有微小差异，影响却深远。
- **GRPO 的核心贡献是删掉 critic**：以同提示词组内其他回复的相对基线替代价值函数，显存约省 50%，使推理模型的大规模 RL 训练真正可行；减均值让信号相对于提示词难度，除标准差降低对奖励尺度的敏感度。
- **RLOO 从另一方向得到类似结论**：优势为某回复奖励减去其余 K-1 条回复的平均奖励，基线无偏且无需价值模型；更关键的是它放弃 PPO 式裁剪，回到纯 REINFORCE 更新——作者称裁剪激活率不足 5%。
- **Dr. GRPO 揭示归一化会引入隐蔽偏置**：序列级奖励被样本级均值均摊后，倾向强化简短的正确回复、弱化惩罚冗长的错误回复，制造「过度冗长」激励；修复方式是固定常量归一化并移除标准差除法。
- **DAPO 提出四项具体改进**：token 级而非样本级聚合、非对称裁剪（放宽上界 ε_high）、超长奖励塑形（硬截断前的软惩罚区）、动态采样（丢弃全对或全错的组以保证每步都有梯度信号）。
- **CISPO 与 DPPO 重新定义「信任域」**：CISPO 把裁剪与梯度流解耦，只裁剪重要性采样权重并施加 stop-gradient，MiniMax 报告单步训练效率约 2 倍提速；DPPO 则质疑「采样 token 的概率比」不是合适的散度度量，改用 TV/KL 散度掩码。
- **MaxRL 与 ScaleRL 提供更宏观的视角**：MaxRL 论证最大似然梯度实为 pass@k 梯度的调和混合、标准 RL 只保留第一阶项，并定义可截断的目标族；ScaleRL 以 40 万+ GPU 小时消融证明，规模化后真正重要的是异步流水线、无 critic、提示词级聚合、FP32 logits 等设计选择。

## 深度分析

### 为什么 LLM 把 RL 问题大幅简化

标准 RL 中，智能体观察状态 s_t、依策略选动作 a_t、按环境动态转移并获得奖励 r_t，目标是最大化带折扣因子的期望回报，并依赖价值函数与优势判断动作好坏。LLM 场景被大幅简化：给定提示词 x，模型 π_θ 采样生成回复 y，再用标量奖励 r(x, y) 打分，目标即最大化该期望奖励。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

作者指出，理论上仍可把「提示词加已生成 token」当成状态、把下一个 token 当成动作，但实践中无法为单个 token 分配有意义的奖励——强行分配则除末位 token 外全为零。这一简化剥离了环境动态、折扣因子与多步信用分配，使问题退化为单步 bandit 式优化，REINFORCE 这类最简单的估计器就够用；但**回复内部的 token 级信用分配并未消失，只是被隐藏了**，这正是后续所有变体反复纠缠的根源。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

### REINFORCE → PPO：重要性采样、clip 与 critic 的成本

REINFORCE 与监督微调的梯度对比表明，它本质上是一种**带权重的 SFT**——不再强化外部提供的异策略答案，而是依奖励对采样的同策略回复加权；其致命弱点是方差大，故需减掉与采样回复无关的基线 b(x)，而 r(x,y) − b(x) 就是最简单的优势估计。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

PPO 在此之上引入重要性采样比例 π_θ/π_old，纠正推演数据生成后策略已不一致的轻微异策略性；裁剪近似实现信任域，关键在于被裁剪的情形产生零梯度、整套更新被跳过，因此 PPO 可理解为「带信任域掩码、经重要性加权的策略梯度」。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

PPO 的真正成本来自优势估计：GAE 需要学习到的价值函数，即一个参数量常与策略模型相当的额外价值模型；此外目标常加对 π_ref 的 KL 正则（RLHF 中它保留通用能力，推理 RL 中通常极小甚至省略）。合起来看，PPO 的内存账是四个大组件同时驻留，这解释了为何后续方法的共同主题是「砍组件」而非「改公式」。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

### GRPO 及其变体：组内基线替换 critic 的收益与新的失败模式

GRPO 由 DeepSeekMath 提出、DeepSeek-R1 发扬光大：为每个提示词采样 G 条回复并在组内归一化奖励以得到优势——基线不再是价值函数，而是同提示词下其他推演的表现；减均值让信号相对于提示词难度，除标准差降低对奖励尺度的敏感度，这在奖励稀疏但每提示词可获得多样本时尤其有效。但作者强调，GRPO 成功的更重要原因其实很简单：**它移除了 critic 模型**，大幅降低内存占用。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

「删掉 critic」换来的是新的失败模式，而这些正是后续变体的修正对象：

- **长度偏置**：样本级损失归一化（先序列内平均、再跨序列平均）把序列级奖励均摊到所有 token，使较长回复在正确时受强化更弱、在错误时受惩罚也更弱，从而产生过度冗长的激励；Dr. GRPO 的修复是改为除以固定常量。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]
- **标准差归一化放大已解决的问题**：当一组内答案几乎全对（奖励方差极低）时，微小差异被放大成巨大优势，模型在「基本已答对」的提示词上收到极不相称的更新；而一组全对或全错时优势全为零、毫无梯度——DAPO 持续采样直到出现正负混合，ScaleRL 则直接排除这类提示词以加速训练。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]
- **信任域的再审视**：DAPO 认为对称比例裁剪对低概率 token 过严，抑制了罕见但有用的推理延续，故改用非对称裁剪；CISPO 指出被裁剪 token 往往正是「However」「Wait」「Aha」这类推理分叉点，屏蔽其梯度会拖慢学习，于是只裁剪权重并施加 stop-gradient；DPPO 则主张概率比在训练/推理框架存在差异时对罕见 token 剧烈波动，远不如总变差等散度度量稳定。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

### 从「算法小改」到「深远影响」

串起来看，可以得到一个反直觉的结论：**该领域的进步主要不是新目标函数的胜利，而是对既有目标函数中各组件「非中立性」的逐步发现**。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

以推理长度为例：DeepSeek 把训练中回复长度的大幅增长归因于推理与反思能力的提升（著名的「顿悟」时刻），但 Dr. GRPO 指出损失归一化本身就会制造冗长倾向——部分长度增长可能是损失聚合方式的副产品，而非纯粹的涌现能力。在目标层面，MaxRL 指出标准 RL 优化期望奖励（pass@1），而 pass@1 的提升常以牺牲 pass@k 与多样性为代价；作者证明最大似然的梯度实为 pass@k 梯度的无限调和混合，标准 RL 只保留第一阶项，因而定义受算力索引截断的目标族并给出无偏估计器，把学习信号集中到成功率低但不为零的困难提示词上，更好地保留多样性、改善测试时算力扩展效率。^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

ScaleRL 则用超 40 万 GPU 小时的消融和 S 型「性能—算力」曲线，分离了两个常被混为一谈的变量：给定预算下的提升速度，与最终到达的渐近上限。作者对证据基础的批评也值得重视——大部分结论仍停留在实证层面、适用范围狭窄且复现成本高，许多论文只测试单一模型家族、单一验证器与固定算力预算，且几乎全部突破都来自验证成本低廉、对错分明的数学与代码领域。**缺乏可用算法已不再是瓶颈，真正棘手的是效率、鲁棒性与泛化能力。**^[raw/articles/强化学习的进化从ppo到maxrlllm推理训练的算法演进史.md]

## 实践启示

1. **优先选择无 critic 的配方。** 自 PPO 之后每种方法都证明组均值、留一法或贪婪推演等简单基线能达到甚至超越学习到的价值函数，同时省下约 50% 内存；LLM 微调从强预训练检查点起步，PPO 的方差削减机制回报有限。
2. **把损失聚合与优势归一化当作一等超参数。** 序列级平均会扭曲每个 token 的学习信号、制造冗长偏置，标准差归一化会让模型过度关注几乎已解决的问题；Dr. GRPO、DAPO 与 ScaleRL 的消融一致指向 token 级或提示词级聚合。
3. **在信任域处理上偏向更柔性、更有原则的方案。** PPO 的 ε=0.2 已相当稳健，但对称裁剪对低概率 token 过严；可考虑非对称裁剪、只裁剪权重并用 stop-gradient（CISPO），或基于 TV/KL 散度估计的掩码（DPPO），并注意极少部分更新就能主导不稳定性。
4. **明确优化的是 pass@1 还是 pass@k 与多样性。** 若下游依赖测试时算力扩展，期望奖励未必是正确目标：MaxRL 表明把信号偏向困难提示词可改善 pass@k 并保留输出多样性；若只关心单次采样质量，常规期望奖励目标更直接。
5. **用「性能—算力」曲线而非单一检查点评估方法。** ScaleRL 的 S 型曲线表明早期学习速度与渐近性能不可互相替代；选型时先锁定自己的算力预算区间，并注意异步流水线、FP32 logits 计算语言模型头等工程细节在规模化后对渐近性能的影响可能不亚于算法选择本身。
