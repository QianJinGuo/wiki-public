# 腾讯 Hy-Embodied 具身智能基座模型与钛螺丝平台全面升级

## 核心：首次系统性打通"感知—身体—行动"闭环

7月18日，腾讯 Robotics X 实验室、福田实验室联合腾讯混元发布具身智能系列新模型和智能体新成果，首次系统性打通"感知—身体—行动"的闭环，推动具身智能从"离身智能"迈向"具身原生智能"。发布的三个具身基座模型都基于混元大模型打造：^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md]

- **Hy-Embodied-VLM-1.0**（"右脑"）：理解图像、空间和场景
- **Hy-Embodied-RxBrain-1.0**（具身"大脑"）：统一认知、规划和对未来状态的想象
- **Hy-Embodied-VLA-0.5**（连接"小脑"和身体）：把高层目标转化成连续的、可纠错的动作

同时发布两个具身智能体 **Apexio** 和 **TairosAgent**，通过智能体调度能力把"左右脑"、"大脑"、"小脑"和身体整合成完整系统，让机器人形成持续感知、持续决策、持续行动的整体。^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md]

## 张正友："缸中之脑"批判

腾讯首席科学家、Robotics X 实验室主任张正友指出：今天最聪明的人工智能本质上仍是"缸中之脑"——善于逻辑推理、文本生成和知识问答，却缺乏与物理世界直接互动的闭环。**"语言并不等于全部认知，它只是智能向外表达的一个通道。"** 真正的智能需要让语言、视觉、空间认知、身体控制和环境反馈连通起来，在"感知—身体—行动"的闭环里接受验证。^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md]

## 深度分析

### "右脑—大脑—小脑"分工：用神经科学隐喻组织模型栈

Hy-Embodied 三个基座模型不是三个平行的通用模型，而是一条按人脑分工切开的流水线。VLM-1.0 充当"右脑"，其能力被刻意设计成三层递进——"看物知用"（识别深度、方位、功能部件与可操作点）、"看景知变"（预判下一步动作带来的变化）、"看远知返"（长时程任务中记忆历史、跟踪进度、失败后分析原因并重新规划）^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:36-42]。这实际上把"感知"从像素级识别升级为"可供性 + 动态预测 + 长程记忆"的组合。RxBrain-1.0 则把"会推理"与"会想象"合并进一个世界认知模型：一边用语言输出步骤与约束，一边生成每步完成后应达到的目标图像，让下游动作模型不仅"听到做什么"，更能"看到做成什么样"^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:46-48]。工程上这是把世界模型的未来状态预测变成了动作模型的对齐目标——与 [[concepts/world-models|世界模型]] 领域"用预测未来状态约束行动"的思路同向，[[entities/baai-orca-next-state-prediction-world-model|智源 Orca 下一状态预测世界模型]] 走的也是这条路线。

更值得注意的是规模取舍：VLM-1.0 仅以 A3B 规模、约十分之一的计算量就接近上一代 A32B 旗舰的效果，更轻量、更适合机器人端直接部署^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:44]。具身端侧算力、功耗与延迟的硬约束，让"够用的轻模型 + 更好的数据与训练技巧"压倒了"更大的基座"。

### VLA 的护城河是学习栈与数据基础设施，不是参数

VLA-0.5 的核心竞争力被明确表述为"数据—模型—训练—部署"协同发力的完整学习栈，而非训练一个更大的模型；其数据底座是亚毫米级精度的 UMI 采集系统积累的超一万小时人类示教数据^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:52]。第三方 RoboDojo 评测中拿下仿真综合第一，且在最考验连续执行能力的长程任务与记忆任务两个维度同样第一^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:54]，本质奖励的是数据质量与训练管线。工业实测印证了这一点：在一家高混合、小批量、SKU 频繁迭代的日化工厂，作业成功率高于 95%、节拍快于 6 秒/件，新增 SKU 的数据采集与后训练不到 3 天^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:58]。最后一个数字才是要害——真正的瓶颈是"换一个任务要多快能再训练"，杠杆全在数据基础设施上。这与 [[entities/lingbot-vla-2-60000h-open-source-vla|灵宝 VLA-2 用六万小时数据开源 VLA]]、[[entities/embodied-ai-data-market-landscape-97-players-44-billion-2026|具身智能数据市场格局]] 的信号一致：具身智能的竞争重心正从模型移向数据。

### 智能体层：用频率分层与双驱动实现"持续在线"

Apexio 的设计要点是三层以不同频率同时在线：认知系统按需唤醒、可做深度思考；感知行动系统以约 15Hz 持续接收多模态信息并快速调整；执行系统以更高频率运行，像条件反射一样瞬间处理碰撞与失衡^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:64-70]。再配以"目标驱动"（完成任务）与"生存驱动"（维护安全、控制能耗、管理运行状态）两条牵引线，机器人即便没有外部指令也持续感知、持续自保、为下一次行动做准备^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:72]。这回答了具身智能体与纯软件 Agent 的最大差异：软件 Agent 可以"被调用才运行"，机器人必须时刻在线——频率分层就是把"思考的慢"与"反射的快"装进同一系统的方法。TairosAgent 则从设计第一天起为机器人本体而生，持续维护环境、本体、任务三类记忆，配合统一硬件适配层与标准化 Skill 接口，把被打断后恢复等场景的响应时间从通用框架的几十秒压到 2—3 秒^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:74-78]。

平台层面，钛螺丝（Tairos）的升级把"模型开源"推进到"智能体开放"，继续提供模型、智能体与开发工具，降低从模型到本体再到应用的全链条开发门槛^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:174-176]。其与宇树、智元等本体厂商及博世、蓝思等场景伙伴的合作^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:178]，加上"可靠地连接模型、本体、工具与应用"的"钛螺丝"定位^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:180]，表明腾讯卡位具身生态的"连接件"。

### "缸中之脑"批判为什么成立：语言只是通道

张正友的论点可拆成两层。其一，今天最聪明的大模型仍是"缸中之脑"——善于逻辑推理、文本生成与知识问答，却缺乏与物理世界直接互动的闭环：未必真正理解物体位置、空间关系与可操作性，也难以在持续变化的环境中边行动、边接收反馈、边及时调整^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:24]。其二，"语言并不等于全部认知，它只是智能向外表达的一个通道"^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:26]——真正的智能需要让语言、视觉、空间认知、身体控制和环境反馈连通起来，在"感知—身体—行动"的闭环里接受验证^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:28]。两层合起来解释了为什么具身数据突然变得关键：力觉、触觉、视觉与示教轨迹是语言通道之外的认知来源；"小六"按摩机器人用融合三者的采集系统获取手法数据，再经强化学习精准复现轨迹与力道^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:188]，正是"用身体获得认知"的具体样本。这一判断与 [[entities/embodied-native-llm-embodied-intelligence-new-stage|具身原生智能阶段论]]、[[entities/genesis-ai-gene-25-embodied-foundation-model|Genesis Gene-25 具身基础模型]] 指向同一趋势：智能的下一步验证场在物理世界。

## 实践启示

1. **端侧部署优先轻模型**：A3B 规模 + 约十分之一算力逼近 A32B 旗舰^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:44]——机器人端按算力/功耗预算选型，把预算花在数据与训练技巧上，而非参数规模上。
2. **先建采集管线，再谈 VLA**：亚毫米级 UMI 系统 + 超一万小时示教是 RoboDojo 三项第一的前提^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:52-54]，做 VLA 的第一笔投资应投向数据采集基础设施而非训练集群。
3. **把"目标图像"当验收信号**：RxBrain 为每步生成目标图像^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:48]，提示可将世界模型的未来状态预测用作执行过程的失败检测器与重规划触发器，而不只是可视化。
4. **工业落地从"高混合、小批量"切入**：95%+ 成功率、6 秒节拍、新 SKU 后训练不到 3 天^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:58]——快速适配能力比单点精度更能定义具身智能的商业价值。
5. **分层频率 + 双驱动是"持续在线"范式**：按需唤醒的慢思考、约 15Hz 的感知行动、更高频的反射执行，加上目标驱动与生存驱动^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:64-72]，可迁移到其他全天候在线的自主系统。
6. **借平台生态而非自研全家桶**：钛螺丝以开源模型 + 开放智能体 + 统一硬件适配层降低全链条门槛^[raw/articles/腾讯发布多款具身智能基座模型与智能体钛螺丝平台迎来全面升级.md:174-176]，中小团队优先在平台内组合能力，自研留给差异化场景数据。
