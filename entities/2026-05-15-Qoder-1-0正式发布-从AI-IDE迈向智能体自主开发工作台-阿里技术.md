## 摘要

阿里技术公众号宣布发布 Qoder 1.0，产品从 AI IDE 升级为智能体自主开发工作台：用户只需专注需求定义，Agent 团队即可"自动驾驶"完成执行、验证和交付全流程，支持 Windows、macOS、Linux。核心升级包括：Quest 从 IDE 内模式升级为独立视窗（Agent-first 开发台，集成任务管理、状态追踪、产物审查和知识调用，与 Editor 双窗口并行、任务委派与协同编程自由切换）；跨项目多任务并行扩展到跨 Workspace 维度，统一面板追踪所有任务（运行中/等待确认/已完成状态标签，完成后自动生成 Summary 交付清单）；团队共享知识引擎（全球首次实现团队知识共享机制）——将记忆、Repo Wiki、Knowledge Cards 整合为统一团队级知识引擎，实测代码保留率提升 11%、输入 Token 消耗降低 40%、对话轮次减少 33% ^[raw/articles/2026-05-15-Qoder-1-0正式发布-从AI-IDE迈向智能体自主开发工作台-阿里技术.md]

Experts 专家团模式从 Chat 侧边栏正式引入 Quest 视窗：专家团由规划、调研、编码、审查、测试五类专家组成，以流水线方式协同交付；1.0 新增自定义专家能力，开发者可创建专属 Agent 团队并配置领域知识、任务技能和外部工具接口。产品升级背后是底层 Agent Harness 的系统性重构，沿两条路径：把传统聊天对话升级为结构化的任务运行时（Task Runtime），把分散的上下文供给收敛为贯穿运行时的知识工程（Knowledge Engineering）。Qoder 旗下产品包括 IDE、CLI、JetBrains 插件、移动端、QoderWork、QoderWake，自 2025 年 8 月上线以来已服务全球超 500 万用户 ^[raw/articles/2026-05-15-Qoder-1-0正式发布-从AI-IDE迈向智能体自主开发工作台-阿里技术.md]

## 关键要点

- Quest 独立视窗：Agent-first 开发工作台，文件目录、代码变更、终端输出、浏览器预览等工程信息按需展开，不离开任务上下文即可深入项目细节。
- 团队知识引擎三类知识：记忆（表达习惯、技术偏好、团队规范、历史决策）+ Repo Wiki/Knowledge Cards（架构知识、模块关系、编码规范、技术栈）；知识云端统一存储，成员可贡献和修正，支持过程审计。
- 知识引擎实测收益：代码保留率 +11%、输入 Token 消耗 −40%、对话轮次 −33%。
- 专家团流水线：规划 → 调研 → 编码 → 审查 → 测试五类专家协同交付；支持自定义专属 Agent 团队。
- Harness 重构两路径：Task Runtime（聊天对话 → 结构化任务运行时）+ Knowledge Engineering（分散上下文 → 贯穿运行时的知识工程）。
