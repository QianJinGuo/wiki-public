GEPA 提出了一种面向 LLM workflow 和 agent 的提示词优化方法：它不更新模型权重，而是让模型阅读自己的执行轨迹、错误反馈和评分结果，用自然语言反思出新的 prompt，并通过 Pareto frontier 保留多条有潜力的进化路线。 ^[raw/articles/gepa-reflective-prompt-evolution-iclr2026-oral.md]
