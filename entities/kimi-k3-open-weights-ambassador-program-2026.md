# Kimi K3 开放权重与全球大使计划

月之暗面（Moonshot AI）在发布 Kimi K3 模型的同时，开放了模型权重、技术报告，以及三项关键 Infra 技术（MoonEP、FlashKDA、AgentEnv），并启动全球大使计划。^[raw/articles/开放k3权重抢招全球大使kimi这次想干什么.md]

## 开放内容

### 模型权重

Kimi K3 的完整模型权重向全球开放，包括预训练权重和后训练权重。这是继 DeepSeek 之后又一个选择完全开源的中国大模型。^[raw/articles/开放k3权重抢招全球大使kimi这次想干什么.md]

### 三项 Infra 技术

| 技术 | 功能 | 创新点 |
|------|------|--------|
| **MoonEP** | 模型并行框架 | 专家并行 + 数据并行混合策略 |
| **FlashKDA** | 注意力加速 | 针对长上下文场景优化的 KV Cache 管理 |
| **AgentEnv** | Agent 训练环境 | 支持多步推理和工具调用的强化学习环境 |

这三项技术是 K3 训练和推理的基础设施，开放后可帮助社区复现和改进大模型训练流程。^[raw/articles/开放k3权重抢招全球大使kimi这次想干什么.md]

### 全球大使计划

月之暗面启动全球大使招募，目标是在全球范围内建立 Kimi 生态的开发者社区。大使可以获得早期模型访问权、技术支持和品牌曝光。^[raw/articles/开放k3权重抢招全球大使kimi这次想干什么.md]

## 战略分析

Kimi K3 的开放策略与 DeepSeek 形成对比：
- **DeepSeek**：完全开源 + 社区驱动，靠技术口碑建立影响力
- **Kimi K3**：开源权重 + 有组织的大使计划，试图建立更结构化的生态

两项策略各有优劣：DeepSeek 的社区更自发，Kimi 的更可控但需要持续投入。
