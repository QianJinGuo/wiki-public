## 摘要

卡内基梅隆大学联合北卡罗来纳州立大学与 Socket Inc. 的论文《Six Million (Suspected) Fake Stars on GitHub》将在 ICSE 2026 主会议宣讲：团队全量扫描 2019 年 7 月至 2024 年 12 月的 GitHub 公开事件数据（在 Google BigQuery 上约 20TiB），检出 600 万颗疑似假星、18617 个涉事仓库、30.1 万个相关账户。假星已形成灰产市场，刷一颗报价低至 0.1 美元（1 美元买 10 颗）；2024 年 7 月为峰值，当月收到 star 的热门仓库中 16.66% 涉及假星活动，2024 年 3 月 GitHub 活跃用户中有 6.59%（117024 个账户）与假星相关。检测方法盯两个维度——低活跃一次性账号与 lockstep 群体同步异常（思路类似 Facebook 抓虚假点赞的 CopyCatch），并公开了 StarScout 源码与数据。面板回归显示假星只在不到两个月内有微弱促进（约为真星效果的五分之一），长期反而是负资产；更严重的是，18617 个涉事仓库中 90.42% 已被 GitHub 删除（随机对照仅 5.03%，18 倍差距），仍在线的样本中约 30% 属于 spam/钓鱼/恶意软件——假星相当大一块是给恶意软件"化妆"用的（如伪装成 Solana 抢购工具的 PhantomSniper-Solana-Sniper-Bot，109 颗假星，代码藏 spawn() 调用窃取加密货币）。文末以坎贝尔定律与古德哈特定律解释 star 指标的异化，并给出降低 star 权重、差异化 star、纳入难伪造信号三条治理建议。^[raw/articles/2026-05-05-1美元买10颗星-顶会曝出GitHub假星灰产-热门仓库或藏木马-新智元.md]

## 关键要点

- 核心数字：600 万颗疑似假星、18617 个涉事仓库、30.1 万账户（2019.7-2024.12 全量 GitHub 事件数据，约 20TiB）；假星占全站 star 约 1%，但高度集中在热门仓库与活跃用户两个最影响决策的区域
- 时间线：2024 年 7 月为假星活动峰值（当月热门仓库 16.66% 涉假）；2024 年 3 月 6.59% 活跃用户（117024 账户）与假星相关；Socket 2024 年 8 月首次披露 370 万颗，四个月后样本扩到 600 万
- 检测方法：盯低活跃账号（无头像/简介/项目、注册当天只点星）+ lockstep 同步异常（一批账号短窗口集中给一批仓库点星），后处理只标记历史上有明显假星异常峰值的仓库以降低误报；StarScout 工具开源
- 经济与效果：刷星单价低至 0.1 美元；面板回归显示假星短期（<2 个月）微弱促进仅为真星的五分之一，长期假星历史越多后续真星增长越差；涉事仓库标题高频词为 awesome、template、demo、example
- 安全风险：涉事仓库 90.42% 已被 GitHub 删除（对照组 5.03%）；在线样本约 30% 为 spam/phishing/malware，Spam/Phishing 单项占 31.1%；典型手法是伪装游戏外挂、破解版、加密货币机器人
- 治理建议与理论：降低 star 在声誉体系权重、引入差异化 star（按账号历史区分）、纳入 release 节奏/依赖关系/issue 质量/PR 合并/贡献者多样性等难伪造信号；引用坎贝尔定律与古德哈特定律解释"轻量信任信号"的系统性异化（对照 XZ Backdoor 供应链攻击）
