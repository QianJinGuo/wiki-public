# ARGUS：多智能体取证推理的泛化 Deepfake 视频检测

北京交通大学、清华大学与蚂蚁集团提出的多智能体协作视频鉴伪框架（arXiv:2608.06865），核心范式转换：**从"看结果"到"找证据"**——检测过程留下可检查的中间观察，将"看到了什么"与"因此如何判断"明确分开。^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

## 架构：独立观察者 + 裁判

传统鉴伪器直接把视频映射为 Real/Fake，无法回答异常来自皮肤纹理、光照还是跨帧运动；且多个模型沿同一错误直觉连续推理时，只会把初始误判包装得更完整。ARGUS 的关键设计是让证据收集**彼此独立**——观察智能体在观察阶段不输出最终真假结论：^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

- **纹理观察者**：皮肤、头发、背景的细节/平滑度/融合痕迹；
- **光照观察者**：高光、阴影、物体间照明一致性；
- **运动观察者**：面部/头发/背景/物体的时间变化比较；
- **物理观察者**：人体生理、几何关系、物体运动规律的不协调。

裁判智能体接收各观察报告（可结合抽取的视频帧），权衡相互印证或冲突的证据，输出二元预测 + 取证解释。^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

## FaceVid-Forensics-100K 数据集

100,000 段视频（21,075 真实 / 78,925 伪造），覆盖人脸替换、人脸重演、整脸生成，纳入 Seedance 2.0 等近期生成方法，共 33 种合成方法。重点是**更细粒度的文本监督**：多模型聚合与冲突消解流程生成视觉观察标签 + 与 verdict 一致的取证解释标签。^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

## 训练：先观察后裁判（SFT + GRPO）

基座 Qwen2.5-VL-7B，两阶段：①SFT 分别训练观察智能体与裁判；②冻结观察者，仅用 GRPO 优化裁判——奖励依据最终判断正确性，KL 约束限制相对 SFT 策略偏移（优化分类决策，不直接等于每条解释更准确）。角色分工减少观察阶段过早下结论的影响。^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

## 结果：OOD 泛化

域外测试集 7,636 段视频（5,716 真实 / 1,920 伪造，伪造来自 20 个训练未用生成器）：裁判同时接收观察报告+视频帧时，Accuracy 69.87% / Recall 81.82% / F1 53.28%，均为主表最高——超越小型视觉模型、开源多模态大模型及前沿闭源模型（GPT-4o、Gemini 3.5-Flash）。专门考察未见生成器/身份的泛化。^[raw/articles/北交清华等提出argus多智能体协同断案给视频鉴伪补上证据链.md]

## 方法论意义

这是"分工观察 + 证据裁决"的多智能体模式在鉴伪任务上的系统化应用，与 [[entities/让gui-agent不再边做边忘快手浙大提出memgui-agent攻克长程gui任务|MemGUI-Agent]] 的"分工+裁决"多智能体思路同构：观察者不越权下结论、裁决者面对冲突证据做权衡——可迁移到任何需要可解释证据链的判断型 Agent 系统。
