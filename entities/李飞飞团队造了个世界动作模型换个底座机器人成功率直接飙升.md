# OpenWAM：可组合世界动作模型开放框架

## 深度分析

斯坦福李飞飞/吴佳俊/Ehsan Adeli 团队发布 OpenWAM（arXiv:2610.07922），回答 WAM 领域「不知道哪个设计带来提升」的归因难题：共享 MoT 底座 + 四种可配置的视频-动作交互方式（先想象再动作/先动作再想象/同时/分离）+ 三阶段训练，用控制变量法分离各设计贡献。底座 Wan2.2-5B，334 万条机器人+人类交互视频（约 1.46 万小时）无动作标签预训练，32×B200 训练 14 天。第二个洞察：机器人数据几乎全是成功示范、缺反事实数据，OpenWAM 用大规模反事实数据补「手多伸两厘米会怎样」。背景：FLUX 3 Action（BLF 7B）在 RoboLab-120 超 Cosmos 3 Nano、参数量不到一半。 ^[raw/articles/李飞飞团队造了个世界动作模型换个底座机器人成功率直接飙升.md]
