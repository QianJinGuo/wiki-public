# ICML 2026 | 多模态思维链真的靠谱吗？川大新框架拒绝噪声思维干扰

## 核心内容

让你更懂AI的 2026-08-06 23:40 江苏 用可靠度筛掉错误思路 引言 随着 OpenAI 在 2025 年发布最新推理模型 o3 [1]，Thinking with Images（TWI）[2][3] 已迅速成为提升多模态大模型（MLLM）推理能力的主流范式之一。 这也意味着，多模态大模型不再单纯依赖文本思维链进行推理，而是学会了像侦探一样，通过两大核心步骤构建多模态思维链，来解决复杂视觉问答任务： 线索搜集（Cue Mining）：审视复杂图像，锁定关键细节，提取视觉线索。 答案推理（Answer Reasoning）：串联视觉线索，整理逻辑思维，逐步推导答案。 然而，现有 TWI 范式往往忽略了由于错误线索和错误推理导致的噪声思维问题，使得 MLLM 在思考过程中陷入“一步错，步步错”的困境。 针对此，来自四川大学的研究团队提出了一种即插即用的 Test-time Scaling（TTS）新框架，有效缓解了噪声思维对多模态推理性能的负面影响，有望推动 TWI 迈向“可信赖”的推理。 目前该论文已经被人工智能国际顶级会议 ICML 2026 录取。 论文标题： Reliable Thinking with Images 论文链接： <https://arxiv.org/pdf/2602.12916 代码链接： <https://github.com/XLearning-SCU/ReliableTWI 背景与挑战 Thinking with Images 旨在通过构建图文交错的思维链来促进多模态大模型解决复杂的推理任务。 具体而言，TWI 范式首先通过生成文本思维。^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md]

## 深度分析

### 问题定义：多模态思维链中的"噪声思维"

TWI 范式让多模态大模型（MLLM）像侦探一样分两步解决复杂视觉问答：先做线索搜集（Cue Mining），审视复杂图像、锁定关键细节、提取视觉线索；再做答案推理（Answer Reasoning），把视觉线索串联成逻辑思维逐步推导答案^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:18-24]。川大团队指出，这条链路的两个阶段都可能出错：线索搜集类似"大海捞针"，从冗余视觉信息中极易提取到任务无关或粗粒度的线索；即便拿到高质量线索，模型理解能力有限仍会产生错误思考^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:53-57]。错误沿思维链传播并累积，形成"一步错，步步错"的噪声思维问题^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:29-31]。作者还统计了真实数据集中的错误原因：不正确的答案往往可追溯至错误的线索搜集或答案推理阶段——噪声思维不是边缘情况，而是 TWI 准确率损失的主要来源^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:53-57]。

### 为什么现有 Test-time Scaling 搬不过来

TTS 是提升推理准确率的成熟思路，但现有方法全部面向文本思维链设计^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:59-61]。直接迁移到多模态场景有两大障碍。其一，文本词元离散且符号化，视觉信号连续且非结构化，视觉不确定性本身就更难建模；而且视觉不确定性并不等同于线索不确定性——前者可能仅反映图像质量，无法说明视觉线索是否与当前任务相关^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:61-65]。其二，此前没有研究探索错误的视觉线索如何传播并干扰后续文本推理过程，自然谈不上设计针对噪声思维的鲁棒策略^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:63-65]。因此 RTWI 的切入点不是"造一个更好的采样器"，而是先回答"如何度量多模态推理过程中的可靠性"。

### 方法核心：以文本为中心的可靠度建模

直接估计视觉可靠度极其困难且缺乏衡量标准，RTWI 另辟蹊径：回归线索搜集阶段的本质——视觉线索的获取是由工具调用指令驱动的，可靠的文本指令即为获取正确线索的"先决条件"^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:86-90]。据此它采用以文本为中心的可靠度建模，统一量化线索搜集与答案推理两个阶段的可靠度^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:90-92]。在此之上论文总结出两大核心观察：可靠度关联——"底气越足，答案越准"，模型在两个阶段的可靠度与最终答案准确度高度相关；可靠度跃升——从"心虚"到"笃定"，正确的视觉线索往往带来更大的可靠度增益，而成功与失败案例的对比显示，当前阶段的错误会传播到后续思考、压低两阶段可靠度与跃升幅度^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:96-106]。这两个观察把"模型是否在瞎想"变成了可计算的信号，是整个框架的地基。

### 双阶段筛选与可信投票：从"一人一票"到"底气加权"

基于两大可靠度特性，RTWI 构造了即插即用的鲁棒 TTS 框架，包含双阶段筛选与可信投票两个组件^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:112-116]。双阶段筛选：对多路采样的推理路径不做盲目信任，而是按线索搜集与答案推理两阶段各自的百分位阈值筛掉不可靠路径，"去伪存真"^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:121-125]。可信投票：双阶段过滤后仍需在剩余候选中确定答案，此前的多数投票忽略了推理路径本身的质量差异，RTWI 将"一人一票"改为基于路径可靠度与可靠度增益的加权投票——"真相"往往掌握在最有底气的路径手中^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:132-136]。实验按在线/离线两种设定展开：在线设定用少量路径估计阈值并在预算内对不可靠路径早停，验证准确率与计算开销能否兼得；离线设定考验从给定路径池中挖掘正确答案的"去伪存真"能力，测试模型为 Qwen3-VL 与 DeepEyes^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:140-149]。结论有三条：准确率大幅领跑的同时保持有竞争力的 Token 节省率（TSR）；计算预算越大优势越大，投入产出比更优；对不同规模的模型均带来显著且稳定的提升^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:153-157]。

## 实践启示

1. **可靠性度量可以先绕开难建模的模态。** 视觉可靠性难估计，但驱动视觉工具调用的文本指令是可靠可算的——找到系统里的"文本控制面"，往往比硬啃模态内不确定性更划算^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:86-90]。
2. **用可靠度信号做早停，省的是真金白银。** 在线设定证明可靠早停能在提升准确率的同时降低 Token 消耗；任何多路采样的 agent 推理管线都可以照此引入"低置信即中止"的预算护栏^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:140-149,153-157]。
3. **投票要加权，不要一人一票。** 多数投票隐含"所有推理路径等质量"的假设；把置信度（这里是可靠度加增益）变成投票权重，是低成本改造现有 self-consistency 管线的第一刀^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:132-136]。
4. **两大可靠度特性可迁移为监控指标。** "可靠度关联"与"可靠度跃升"给了 agent 观测两个新探针：阶段间置信增益骤降，往往意味着上游线索出了问题，可据此定位错误传播的源头^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:96-106]。
5. **TTS 设计必须考虑模态差异。** [[entities/parallelworld-test-time-scaling-agentic-embodied-reasoning-2026|测试时扩展进入具身场景]] 等近期工作正把 TTS 推向 agentic 场景；RTWI 提醒：这些场景里采样与筛选的标准不能照搬文本 N-best 的做法，连续模态的不确定性需要单独的度量与阈值机制^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:61-65]。
6. **可信推理是 agentic 演进的下一个抓手。** 论文展望大模型正从"知识库"进化为能自主操控工具的"指挥官"，即插即用的可信推理思路有望启发更多 Agentic LLM 场景^[raw/articles/icml-2026-多模态思维链真的靠谱吗川大新框架拒绝噪声思维干扰.md:176-178]；这与 [[concepts/tool-use-patterns-ai-agents|AI Agent 工具使用模式]]、[[concepts/agent-evaluation-benchmark-frameworks|Agent 评估基准体系]] 中的可靠性议题同源，并与 [[entities/agentic-abstention-washington-allen-2026|智能体弃答机制]] 一起构成"模型知道自己边界"这条主线。
