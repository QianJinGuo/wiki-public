# RSI-Anything：世界模型驱动的跨域自我进化框架

PhAI Labs 提出的通用 RSI（Recursive Self-Improvement）研究框架：修 Bug、操作计算机、规划实验室操作、优化化学反应、研究免疫系统等跨域任务统一进同一套「世界模型预测 + 真实反馈适配」循环 ^[raw/articles/rsi-anything-phai-world-model-benchmarks-2026.md]。

## 关键实验数字

| 任务 | 结果 |
|---|---|
| 代码修复 | 成功率 26.3% → 31.2%（不换模型、不加测试预算，仅引入世界模型预测选择 + 真实反馈适配预测器） |
| 计算机交互（OSWorld） | 任务成功率相对提升约 18.4% |
| 实验室规划（4B 策略模型） | 连续五代改进，规划分 21.80% → 46.01%，超过更大模型组合的参考系统 |
| 化学反应优化 | 40 次实验平均最佳产率 96.15% vs 贝叶斯优化对照 82.16% |

## 与 RSI 家族的关系

机器之心版（本页主源）与 PaperToday 版（[[raw/articles/rsi-anything-world-model-universal-rsi-papertoday-2026-10-13|前档 raw]]）同述该项目，本版含完整 benchmark 数据。与 [[entities/self-developing-agents-rsi-benchmarks-aspire-s3gym-harnessdev-2026|RSI 基准家族]]的区别：RSI-Anything 的改进信号来自**环境真实反馈对世界模型的适配**，而非权重更新；与 [[entities/ai-recursive-self-improvement-nanogpt-prime-intellect]]（GPU-poor 自我改进）互补于「无梯度自进化」路线。

## 深度分析

### 三步闭环：预演、学习、留用

PaperToday 版将框架概括为「预演—学习—留用」三步闭环 ^[raw/articles/rsi-anything-world-model-universal-rsi-papertoday-2026-10-13.md]：①预演——策略提出候选动作，世界模型逐一预测后果，挑最值得花真实反馈预算的执行（预测性选择）；②学习——真实观测回来后更新策略/工作流，同时检查预测器是否仍然可靠，不可靠才触发模型适配，避免无谓开销；③留用——组件评估加兼容性检查决定新的「策略-模型对」能否进入下一轮，留存版本塑造后续候选与学习数据。机器之心版将其表述为 State → Action → Prediction → Feedback → Improvement 的核心流程 ^[raw/articles/rsi-anything-phai-world-model-benchmarks-2026.md]。两版对读的关键点在于：真实反馈是稀缺资源，世界模型的价值不在替代反馈，而在把有限的反馈预算花在最值得执行的候选上——代码任务中「固定 ReasonFlux-Coder-7B、每轮生成四个候选、只真实执行一个、在线测试调用维持在约 3.7 次/任务」正是这一逻辑的量化体现。该框架建立在 [[entities/jepa-anything-cross-domain-latent-world-model-phai-2026|JEPA-Anything]] 的跨领域预测底座之上（OPF 正交预测分解，覆盖视觉、分子、物理、生命等七类领域），但把世界模型的角色从「预测未来」升级为「连接环境与自我进化的组件」。

### 策略漂移与兼容性检查：多数自我改进方案忽略的环节

机器之心版点出一个容易被忽略的问题：策略更新后 Agent 会探索从未接触过的状态，原本准确的世界模型未必还能可靠预测新的行动；反过来，世界模型更新也会改变 Agent 对候选行动的判断。RSI-Anything 的应对是允许 Policy 与 World Model 异步更新，并引入组件评估与兼容性检查——不是每次更新都被接受，只有通过检验的组合才保留为下一轮改进的起点。PaperToday 版在 GUI 任务中给出了这一机制的实证：过渡「适配版」平均动作数更省（2.93 次/回合）却有 21 次错误提交，最终版把误提交压到 1 次、只多花零点几步——留用检查挑的是综合最稳而非单指标最快。这对 [[concepts/agent-self-improvement-loops]] 是一个重要补充：自我改进循环的瓶颈往往不在「能否变强」，而在「变强后的组件之间是否仍然互相兼容」。

### 四域证据的梯度：反馈信号从廉价到昂贵

四组实验按反馈成本排成一条清晰的梯度。代码任务反馈最廉价：跑测试即可，成功率的提升几乎纯靠「眼光」——候选排序准确率 66.5%→72.8%、Brier 分数 0.488→0.358，静态验证器 26.3% → 固定世界模型 29.2% → 执行反馈适配后 31.2%。GUI 交互反馈居中：每步操作都改变界面状态，OSWorld 相对提升约 18.4%。实验室规划衡量的是实验协议规划质量而非真实湿实验执行成功率：4B 策略模型五代 21.80% → 46.01%，略超 35B Actor + Gemini 3.1 Pro 组成的 Actor–Simulator–Selector 参考系统（45.32%）。化学反应反馈最昂贵：世界模型预测催化剂/配体/溶剂组合的产率排序，真实测量反哺，两组 Suzuki–Miyaura 筛选中 20 次实验 93.0% vs 贝叶斯优化 87.5%、40 次 96.15% vs 82.16%。梯度越靠右，预演的价值越大——这与动机陈述「真实世界反馈昂贵、稀疏、难以直接获得」一致，也解释了框架为何强调反馈预算分配而非单纯的预测精度。这条「用 [[concepts/world-models|世界模型]] 替代部分真实试错」的思路，与 Model-Based RL、Dreamer、MuZero 一脉相承，但把规划器换成了可跨域复用的递归改进闭环。

### 免疫科学：从改进任务表现到提出研究假设

免疫科学是五域中唯一端到端开放式的场景：Agent Genesis 进化出科学智能体工作流 → 构建细胞/组织/个体三层的免疫世界模型（细胞因子、基因扰动、候选疗法作为显式动作预测后果）→ 分析智能体经模拟自纠错排序候选 → 产出 SIRPα 抑制联合 IL-36γ 轴调控的前瞻性治疗假设（仍待实验验证）。与前四域的本质区别在于：前四域改进的是已有任务的解法，这一域的世界模型开始充当科学智能体分析复杂系统、比较干预方案、修正研究判断的工具——从「解决问题」滑向「发现值得研究的新问题」。这也是标题中 Anything 的真实含义：统一的不是数据或参数，而是不同世界中从预测、交互到自我改进的底层机制；论文同时坦言，策略与世界模型在同一复杂环境中长期稳定协同进化仍是待验证目标。

## 实践启示

1. **反馈预算先于模型规模**：代码修复不换模型、不加测试预算，仅靠世界模型预测选择 + 执行反馈适配就把成功率从 26.3% 提到 31.2%（APPS 入门集 46.37%、LiveCodeBench v6 33.05%，同样压过静态验证器与随机选择）。评测预算紧张时，先检查候选选择环节是否还有未被利用的信号，再考虑加算力。
2. **给操作类 Agent 配「预演层」**：GUI 任务中 OSWorld 相对提升约 18.4%，MiniWoB++ 勾选任务 51%→99%、平均动作数 5.30→3.21/回合（-39.4%）、重复点击 237 次清零。行动前的模型预演能同时提高成功率和降低无效操作，适合机器人、RPA、浏览器自动化等连续交互场景。
3. **把兼容性检查做成迭代系统的标配闸门**：实验室规划 4B 模型连续五代稳定爬升（21.80%→38.03%→41.99%→44.56%→46.01%）依赖留用检查淘汰「更快但不稳」的组合。任何多组件自我改进系统（策略 + 验证器 + 模型）都值得加一道「新组合是否通过组件评估」的门槛，而非自动接受每次更新。
4. **昂贵实验优先用预测排序而非盲目探索**：化学任务同样 40 次实验预算多榨近 14 个百分点产率（96.15% vs 82.16%），20 次预算下亦有 93.0% vs 87.5%。湿实验、A/B 测试、超参搜索等高成本探索可直接借鉴「模型排序候选 + 实测反哺」的模式，不必等贝叶斯优化。
5. **监控预测质量，失准才适配**：框架只在预测器不可靠时才触发模型适配，避免无谓开销。生产系统应先持续跟踪预测校准指标（如 Brier 分数从 0.488 降到 0.358 的这类度量），再决定是否投入重训成本。
6. **把科学视为 RSI 能力上限的试金石**：论文明确指出，科学因其复杂环境、昂贵反馈与大量未知问题，可能成为检验智能系统自我进化上限的重要训练场。对研究者而言，跨域统一机制的普适性证据（四域 + 一开放场景均有效）比任何单域 SOTA 更值得关注。
