# TurboT2VA：19B 音视频联合生成的三阶段课程蒸馏

浙江大学、清华大学、新加坡国立大学等团队面向大参数量（19B）音视频联合生成模型的加速方案，在 LTX-2 上将 40 步教师蒸馏为 **4 步学生**。单张 NVIDIA H20、1024×1792 分辨率、121 帧测试设置下：生成器耗时 318.74s → 5.83s，**54.67× 加速**。^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]

## 问题定义：两个成本来源

文本到音视频联合生成的成本来自两个方向：**长采样轨迹**（反复前向计算）与**高分辨率音视频 token**（每次前向很重）。只减采样步数，单步计算仍贵；只优化算子，多步重复计算仍在。TurboT2VA 从训练端（蒸馏）与推理端（量化/算子）同时处理。^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]

## 三阶段课程蒸馏

**训练顺序：dCM warmup → sCM refinement → sCM+DMD 联合优化**，三阶段沿用同一学生模型，变化的是训练目标及引入时机。模型仍是 LTX-2 原架构，"确定初步结构"指建立联合去噪与生成轨迹先验：^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]

1. **dCM（离散一致性蒸馏）warmup**：学生在离散噪声水平间学习一致预测，先确定粗粒度联合去噪结构（基本去噪能力 + 稳定的时间步条件响应）。dCM 不需要连续时间轨迹切线估计，适合 19B 级蒸馏的 warmup（数值稳定性要求低）；
2. **sCM（连续一致性蒸馏）**：学习教师连续生成轨迹，不同噪声水平下预测一致；需同时保留画面运动演变、声音事件发展及两者时间对应关系；
3. **sCM+DMD（分布匹配蒸馏）**：DMD 推动生成结果向教师分布靠近，改善感知质量；持续参与的 sCM 约束轨迹结构，保留随机种子多样性。

## 音视频异构调度与量化

- **分模态时间步 shift**：音频与视频隐变量维度/时间分辨率/学习节奏不同，分别为两个模态设置扩散时间（噪声调度）shift；两模态共享文本条件、通过联合 Transformer 交换信息。注意区分 shift（时间调度）与 CFG guidance scale（引导强度）两类参数，调试时避免混淆；^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]
- **线性层 W8A8**：权重按输出通道静态 INT8、激活按行动态 INT8；INT32 累加完成后统一缩放偏置；分支形状不满足优化算子要求时回退 BF16；
- **注意力 SageSLA**：H20 路径 Q/K 量化 INT8、V 聚合 FP8，高分辨率 Key 块保留比例 0.3；短音频序列保证至少 1 个 Key 块；音视频交叉注意力与文本交叉注意力保持密集计算；
- **算子融合**：归一化/调制/门控残差/RoPE 融合减少中间读写；按共享文本掩码裁剪填充位置。^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]

## 为什么 SCM 与 DMD 要结合

一致性蒸馏约束不同噪声水平下的预测关系（学生沿教师生成轨迹学习 → 少步出结果），但样本质量受轨迹约束上限；分布蒸馏直接改善最终样本质量但缺乏轨迹结构。二者互补：sCM 保轨迹/保多样性，DMD 提质量。^[raw/articles/音视频生成提速54倍turbot2va分布蒸馏与轨迹蒸馏的联合蒸馏方案.md]

## 方法论可迁移性

三阶段课程（先离散 warmup 保数值稳定 → 再连续精化 → 最后加分布目标）+ 分模态异构调度的模式，可迁移到任何大参数多模态扩散/流匹配模型的蒸馏加速，与 [[entities/免蒸馏只改一个loss5行代码实现扩散模型4步生成|免蒸馏 4 步生成]]（推理端路线）形成"训练端蒸馏 vs 推理端修正"对照。

## 深度分析

### 课程顺序的"先广后精"逻辑：为什么分布目标必须延后引入

论文的消融对比给出了课程设计的关键证据：直接联合训练 sCM+DMD 可以收敛并产出合理结果，但分阶段方案在相同训练步数下取得更高的 Javis Score。作者的解释指向一个分布学习的基本矛盾——DMD 利用学生与教师分布的 score 差异提供更新方向，这类分布级约束天然偏向高概率模式；如果学生在尚未沿教师轨迹建立起足够宽的覆盖范围时就接受强分布约束，其结果会趋向构图重复、跨种子差异收窄。先经 dCM warmup 与 sCM refinement 建立"覆盖充分、结构稳定"的轨迹先验，再让 DMD 收紧质量，相当于先保证多样性上限再优化感知下限。这在 19B 规模上尤其重要：连续一致性蒸馏依赖 JVP 估计轨迹局部方向，数值稳定性要求高，离散一致性蒸馏恰好绕开了连续时间切线估计，成为大规模 warmup 的可行起点。

### 加速数字的分层拆解：步数压缩与推理栈是两个乘法因子

官方逐项叠加的耗时数据让"54.67×"可以分解为独立因子。标准分辨率下，40 步教师 50.52s → 4 步学生 2.51s，纯蒸馏带来约 20.1×；高分辨率下，教师在叠加 W8A8 与 FastNorm 后从 318.74s 降到 233.34s（推理栈对单步前向的收益约 1.37×），切换 4 步学生到 12.16s，再加 SageSLA 与文本填充压缩到 5.83s——完整推理栈相对未优化的 4 步学生（16.50s）额外贡献约 2.83×。两个因子正交且可复合，这正是"只减步数单步仍贵、只优化算子重复计算仍在"这一成本结构分析的直接验证。值得注意的是 20.1× 并非以质量换速度：JavisBench 上学生 Visual 指标从教师 1.968 升至 2.389，Motion 从 0.783 升至 0.849，Javis Score 从 0.165 升至 0.196，Desync 从 0.617 降至 0.388——蒸馏学生的指标反而全面优于教师。

### 跨模态联合蒸馏的工程前提：配对前向与双重归一化

联合蒸馏能学到音画对应关系的前提是结构性的：同一样本的视频与音频隐变量分别采噪、共享文本条件、一次前向同时输出两个模态的预测，梯度经同一跨模态计算图回传，连 sCM 所需的 JVP 局部方向也穿过联合 Transformer——轨迹学习因此天然包含模态间相互影响。但两个模态隐变量规模不同，直接相加损失会让某一方主导优化。TurboT2VA 的对策是对目标分别归一化：sCM 对每个模态的方向向量做 L2 归一化后再组合损失；DMD 用学生样本与教师预测之间的残差尺度做归一化，使分布匹配信号相对各模态自身误差大小自适应。归一化之后再叠加模态权重与目标权重控制相对强度，形成"尺度对齐 → 权重调节"的两级控制。

### 量化的分层设计哲学：稀疏化有边界，密集路径保底

推理栈的量化并非一刀切。线性层 W8A8 采用权重静态、激活动态的组合并延后统一缩放，减少分块重复开销；对形状不满足优化算子要求的音视频分支回退 BF16，体现"能优化则优化、不达标则保真"的工程取舍。注意力侧的 SageSLA 只对视频/音频自注意力做稀疏量化（Q/K INT8、V 聚合 FP8、高分辨率 Key 块保留 0.3），而双向音视频交叉注意力与文本交叉注意力保持密集计算——跨模态交互与文本条件路径是生成质量的关键通路，被明确排除在稀疏化之外。这揭示了一条通用原则：稀疏化/量化预算应优先花在自注意力这类冗余度高的计算上，条件通路宁可保守。

## 实践启示

1. **大模型蒸馏先做离散 warmup**：当连续一致性蒸馏的 JVP 在 19B 级模型上数值稳定性吃紧时，用 dCM（无连续时间切线估计）做几千步 warmup（论文用 2000 步）建立基本去噪结构，再切连续目标，是成本可控的稳妥路径。
2. **分布级目标延后引入，不要一步到位**：DMD 这类分布匹配损失过早加入会收窄生成分布、损伤种子多样性；先让轨迹类目标（sCM）跑充分，再联合优化（论文 sCM refinement 仅 500 步后进入联合阶段），消融显示同样的联合训练步数下分数更高。
3. **多模态联合训练必须做逐模态损失归一化**：隐变量尺度不同的模态直接相加损失会被一方主导；sCM 用方向向量 L2 归一化、DMD 用残差尺度归一化，再配模态权重，是可复用的两级控制模板。
4. **调参时区分时间调度与引导强度**：分模态 shift 调的是扩散时间/噪声调度偏移，CFG guidance scale 调的是文本条件引导强度，两者症状可能相似；调试音视频联合蒸馏时分开核对，避免把引导强度差异误诊为调度问题。
5. **加速收益按乘法因子分层规划**：步数压缩（约 20×）与推理栈优化（约 2.83×）相互正交；且推理栈直接叠加在蒸馏学生上无需重训——先蒸馏、后量化/算子优化的顺序可以独立迭代。
6. **量化为关键通路留密集计算兜底**：跨模态与文本交叉注意力保持密集、短音频序列强制保留至少一个 Key 块、形状不合规的分支回退 BF16——给稀疏化/量化设置明确的质量保护边界，而不是追求全图低精度。
