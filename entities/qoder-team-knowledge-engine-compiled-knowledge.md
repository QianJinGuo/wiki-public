2. 核心架构是"编译式知识"——分两层产物：Knowledge Card（给 Agent 用，短/密/结构化）+ Repo Wiki（给人用，连贯叙事）。 ^[raw/articles/qoder-team-knowledge-engine-compiled-knowledge.md]
3. 双链路自迭代：代码侧由 commit/diff 驱动，对话侧由 Memory Agent 驱动。 ^[raw/articles/qoder-team-knowledge-engine-compiled-knowledge.md]

- 接口设计可能藏在三年前的一次事故里
- 代码规范没写进 README，但 code review 时会卡红线
- 知识在聊天记录、提交说明、排查过程和资深工程师脑子里
