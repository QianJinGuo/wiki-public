## 摘要

本文是自媒体创作者叶小钗的实践案例：针对"刷到好视频只能收藏截图、灵感与上下文事后即失"的痛点，他把视频转文字、内容入库的繁琐流程封装成 Claude Skill，并进一步构建了 Krawl——一个基于 Claude Skills 机制的知识库管理系统，实现从内容抓取、整理到知识管理的自动化闭环 ^[raw/articles/2026-05-02--实践案例-我用Skills实现了个自媒体知识管理神器--叶小钗.md]。文章先系统讲解 Claude Skills 的三层结构与 Progressive Disclosure 原则：元数据始终加载进系统提示、核心指令（SKILL.md）触发时经 bash 从文件系统加载、代码与资源按需加载 ^[raw/articles/2026-05-02--实践案例-我用Skills实现了个自媒体知识管理神器--叶小钗.md]。Krawl 的工程实现采用 Dynamic Router + Lazy Loading 架构：SkillManager 启动时只轻量扫描 Markdown frontmatter 不加载 Python 代码，LLM 通过唯一的 Meta-Tool load_skill 自主决定加载哪个技能，activate_skill 时才动态 import execute.py 并注册工具 ^[raw/articles/2026-05-02--实践案例-我用Skills实现了个自媒体知识管理神器--叶小钗.md]。核心技能 link_ingest（链接内容提取入库）与 knowledge_query（知识库检索）遵循"工具定义 + 异步处理函数 + HANDLERS 映射"的标准协议；文末总结了 Skills 的适用场景与粒度把握原则 ^[raw/articles/2026-05-02--实践案例-我用Skills实现了个自媒体知识管理神器--叶小钗.md]。

## 关键要点

- Claude Skills 三层渐进加载：第一层元数据始终在 System Prompt（占上下文极小）；第二层匹配触发时通过 bash 读取 SKILL.md 全文；第三层复杂 Skill 的脚本、模板等资源按需加载
- Claude Code 安装 Skill 的两种方式：官方技能市场（/plugin marketplace add anthropics/skills 后 /plugin install document-skills@anthropic-agent-skills）或手动在 ~/.claude/skills/ 下建目录写 SKILL.md
- Krawl 的懒加载核心：启动时仅遍历目录读取 frontmatter 描述保证启动速度；load_skill 命中缓存直接返回，未加载才读 skill.md 全文并 importlib.import_module 动态导入 execute.py
- 以"保存抖音视频"为例的五步流程：初始化扫描 → LLM 意图识别匹配 link_ingest → 调用 load_skill 动态加载 → 按 Manual 调用 save_link_knowledge 工具 → 组织自然语言回复
- 最佳实践：从解决具体问题的小 skill 开始；一个 skill 只做一件事但避免过碎（按业务领域划分、每个 skill 对应完整用户故事）；为每个 skill 设计错误处理、使用日志与版本回滚
