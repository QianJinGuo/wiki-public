# Noe-0 世界动作模型（无本体数据训练）

穹彻智能（Noematrix）2026-08-26 发布具身智能预训练模型 **Noe-0**——训练全链路采用**无本体数据**的世界动作模型（World Action Model, WAM），证明了完全不依赖传统遥操作数据也能完成具身世界模型的预训练、后训练并在真实机器人上形成执行任务的能力。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

## 核心范式：全链路无本体数据

传统遥操数据在集中场地标准化工位采集（相似桌面、有限物体、预设任务流程），本质是为数据采集人为构造的环境。Noe-0 的所有自采训练数据都来自人在真实环境中直接完成操作的记录——超 50 个城市、数十万小时、数十万种任务类型。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

关键设计是**预训练与后训练始终沿用同一种无本体数据路线**。若预训练用无本体数据、后训练切回遥操作数据，两阶段会出现数据分布和动作模式的断层——模型在预训练学到的自然操作规律，需要在后训练重新适配一套不匹配的动作表达。Noe-0 从预训练到后训练保持数据范式连续，避免后训练成为链路能力瓶颈。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

## WAM 架构与跨本体迁移

Noe-0 采用 World Action Model 架构（对应「VLAs are dead, long live World Action Models」路线，见 [[entities/4d-wam-world-action-model-3d-trajectory-alignment-2026|WAM]]），以视频预测作为核心高层学习目标：接收连续历史帧与状态信息，预测未来视觉状态，同时把状态变化理解转化为可执行动作。动作侧模型规模相对较小，更换末端构型时无需重训整套模型。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

穹彻团队发现：即使采集数据与推理部署之间存在本体差异，**Pixel Prediction 依然能显著提升跨本体迁移**。原因在于像素预测提供隐式反事实推理——模型必须区分哪些视觉变化与任务完成相关、哪些只是本体外观或背景差异，从而过滤掉本体绑定的表面信息、抓取驱动任务进展的物理本质。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

## AI-Native 数据基础设施

穹彻强调「分布规模化」而非「数据量规模化」：`Distributional Scaling = More Data × More Tasks × More Objects × More Spaces × More Real-world Variation`。为了支撑全链路无本体数据，团队打造了 RoboPocket + Data Agent 的数据管线。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

- **RoboPocket**：端侧采集入口，覆盖 50+ 城市、18 省级行政区，三组传感器（左右手+头部）采集视觉与动作轨迹；累计数十万小时，峰值 1000+ 采集员同时参与。任务由采集者在真实场景自主产生（煮面、接线装配、填充缝隙等），产生「数十万小时对应数十万种任务类型、平均每种约 1 小时」的广度远大于深度的数据特征。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]
- **Data Agent**：连接数据管理者与分散采集员的智能体，覆盖任务生成、数据查询统计、质量问题处理、通知推送、权限管控五项功能，把 AI 嵌入任务产生→采集→质量改进的完整管理闭环。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

## 深度分析

### 遥操瓶颈：被构造出来的「真实」

遥操采集锁死在标准化工位：相同桌面、有限物体、预设流程。代价是双重——分布窄（模型见到的「真实」只是工位的统计阴影），动作不自然（同一任务遥操耗时是直接操作的 3–5 倍，轨迹偏慢偏机械）。Noe-0 以 50+ 城市、数十万小时人类直采数据替换工位，把「什么是真实」的定义权交还世界：视角、光照、摆放与长尾不再由采集设计者预先枚举。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

隐性前提是链路一致性：预训练吃无本体数据、后训练却切回遥操数据，就会出现分布与动作表达的断层，后训练反成瓶颈。

### 像素预测：隐式的反事实通道

本体差异（夹爪形状、自由度、相机外参）在像素层面最显眼，也最容易被模型当作捷径。以视频预测作为高层目标恰好把捷径变成训练压力：要预测下一帧，必须先区分「这一变化来自任务推进，还是只是本体自己长什么样」。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

由此得到隐式反事实推理——剥离与本体绑定的表面外观，只保留驱动状态转移的物理量。无本体数据与 WAM 因此相互成就：数据侧缺本体标注，模型侧靠预测任务补上对齐信号；动作侧只做末端适配，换本体成为增量工程（同类路线见 [[entities/dele-w0-5-world-action-model-deepleap-2026|DeepLeap W0.5]]）。

### 基础设施：护城河在「AI 管人」

数千名采集员散布几十座城市各自构想任务，任务类型不可枚举，固定模板与质检规则无法覆盖，管理复杂度随规模非线性上升。Data Agent 把人、任务、质量串成可追踪工作流：AI 初筛任务、自动质检与标注，并将问题实时回推端侧。^[raw/articles/突破遥操瓶颈全新无本体数据世界动作模型noe-0发布.md]

更值得关注的是成本结构：实践中标注成本已超过采集成本。靠加人力扩规模的团队终将被自己的后端吞掉——分布式采集的规模优势，只在自动化同步增长时才成立（参见 [[entities/egosuite-open100k-embodied-human-video-data-open-source-2026|EgoSuite Open100K]]）。

### 边界与开放问题

数据「广度远大于深度」：数十万小时对应数十万种任务、平均每种约 1 小时，长程精细任务能否仅靠后训练补足，尚无公开消融。RoboPocket 动作来自人手，与人形末端在动力学与可达空间上并不等价，「像人一样做」到「像机器人一样做」目前只有 Pixel Prediction 一条线索。此外跨本体提升多以个案演示呈现，缺统一多本体验证基准（参见 [[entities/triworldbench-three-view-embodied-world-model-benchmark-2026|TriWorldBench]]），力/触觉缺席也限制接触密集任务的上限。

## 实践启示

1. **先定分布，再定规模**：用 `More Tasks × More Objects × More Spaces` 衡量数据资产，而非同一任务多采几次；预训练与后训练共用同一数据范式。
2. **把采集工具当产品设计**：同构末端与便携形态决定采集员能进入哪些场景，工具舒适度直接兑换数据自然度，比事后清洗便宜。
3. **迁移评估看像素级任务性**：判断跨本体迁移是否发生，看模型能否过滤本体外观差异，而非只看单本体成功率；引入多视角、多末端验证集。
4. **早建「AI 管 AI」**：一旦标注成本超过采集成本，自动质检与标注就从效率选项变成唯一可持续路径；让反馈在下一次采集前完成干预。
5. **无本体数据不是廉价替代品**：其价值来自与视频预测目标的匹配度；骨干若仍是纯语言式 VLA，分布优势很难兑现。
6. **为换本体预留接口**：高层视频预测复用 + 动作侧小模型适配，能让升级末端成为增量工作而非整套重训。
