## 摘要

文章跟进 Agnes AI 全模态 API 免费开放后的进展：单周调用量达 4.66 万亿（4.66T）Token 创历史新高，其中文本模型 2.80T、多模态模型 1.86T。Agnes 同步推出 PC 端创作平台 Pavo，定位面向非代码创作者的 Agent Native 平台，含 Agent、图片生成、视频生成、剧情短片四个模块，可跑通"剧本创作 → 人物与场景设定 → 分镜设计 → 视频生成 → 成片渲染"的短剧全链路。作者实测认为图片/视频生成稳定性好、交互丝滑，剧情短片功能最惊艳（一次性生成 1 分钟短剧《我的总裁是外星喵》），但 Agent 模块还需打磨、生成过程需要抽卡。此外图片模型 Agnes-Image-2.1-Flash 新增 4K 超高清输出，即将上线的 Agnes-Video-2.5-preview 生成速度提升一倍、改善运镜与物理还原、新增多参考图能力。^[raw/articles/2026-06-29-重磅-全模态API免费后单周被薅4-66万亿Token-Agnes全新Pavo平-AI寒武纪.md]

## 关键要点

- Agnes 全模态（文本/图片/视频）API 于 6 月 1 日由榜单前十的 Agnes AI 宣布无限期免费开放，单周调用量 4.66T Token（文本 2.80T + 多模态 1.86T）
- Pavo 平台四个功能模块：Agent、图片生成、视频生成、剧情短片，面向新媒体运营、短剧导演、设计师等非代码创作者
- 剧情短片模块用自研短剧 Harness 机制定向优化创作流程，全程流式输出，从故事创意到成片一站式完成
- Agent 模块支持上下文记忆与局部修改（第二轮只提修改点即可），但实测稳定性需要加强
- 图片模型 Agnes-Image-2.1-Flash 支持 1K-4K 输出与 1:1 到 21:9 宽高比；Agnes-Video-2.5-preview 生成速度翻倍、新增多参考图一致性锚定
- 费用模式：Agnes 系列模型在 Pavo 内无需会员，部分第三方模型需 Pavo 会员
