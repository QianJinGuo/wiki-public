# 大模型后训练，破解多模态分布性遗忘！7B模型七项基准全线提升

> WeChat-新智元 | 发布于 2026-08-08 | 评分入库 v×c≥49

## 核心内容

新智元 2026-08-08 19:07 北京 新智元报道 DeepSeek-R1之后，「让模型想得更久」几乎成了提升推理能力的标准答案。 但对多模态大模型而言，推理 token 更多，并不必然意味着视觉推理更充分。恰恰相反，模型在开头还能准确描述图像，随着生成内容不断累积，后续推理却可能越来越依赖自己写出的文字。 只要早期描述出现一点偏差，错误就会沿着自回归链条被反复引用、逐步放大，最后得到一个语言上严丝合缝、视觉上完全失真的答案。 这不是简单的「没看见」，而是看见之后没能一直记住 。 从后训练角度看，问题还可以进一步抽象：在典型的自回归多模态模型中，视觉条件在生成开始时已经固定，语言轨迹却随着推理持续增长。如果强化学习只奖励最终答案，训练目标就不会主动区分两类轨迹——一类始终以图像为依据，另一类中途丢失视觉证据、靠语言先验碰巧答对。 久而久之，策略优化就可能把概率质量分配给「答案正确但证据失真」的轨迹。本文将这种由rollout数据分布、序列结构与稀疏结果奖励共同诱发的系统性视觉衰减 ，概括为「分布性视觉遗忘」。 西北工业大学、香港科技大学和浙江大学的研究团队提出Remember-R1 ，试图从源头上修正这一偏置：不修改推理流程，而是在强化学习后训练中加入三种过程奖励，让模型不仅要答对，还必须在整条推理链中持续表达、保留并准确调用视觉证据。 论文链接：<https://arxiv.org/abs/2608.01314 代码链接：<https://github.com/Ch921-cell/Remember-R1 模型链接：<https://huggingface.co/JM。^[raw/articles/大模型后训练破解多模态分布性遗忘7b模型七项基准全线提升.md]

## 深度分析

### 方法：三层过程奖励构成的行为正则化

Remember-R1 不修改推理流程，也不在推理阶段回插原图或增设验证步骤，而是把干预点前移到强化学习后训练阶段。其总奖励可抽象为：

> 总奖励 = 答案正确性奖励 + 视觉词汇奖励 + 视觉记忆奖励 + 视觉关键区域奖励

答案正确性奖励决定模型是否完成任务，另外三项过程奖励约束模型以什么方式完成任务，分别对应视觉证据的三种分布：

- **视觉词汇奖励（语义分布）**：从训练图像中提取物体类别、颜色、大小、数量、空间关系等视觉词组，用严格的词或短语匹配统计回答覆盖了哪些视觉事实；奖励不仅取决于匹配数量，还取决于这些词最后一次出现的位置——不能只在开头说一句"图中有……"随后进入纯语言推理，关键视觉事实必须持续出现在后续轨迹中。
- **视觉记忆奖励（时间分布）**：从模型最后一层提取每个生成步骤对视觉 token 的注意力，比较推理早期与后期的平均水平；后期注意力快速下降则奖励降低。它不要求注意力绝对不变，而是直接惩罚"越想越不看"的系统性衰减。
- **视觉关键区域奖励（空间分布）**：将训练样本的关键区域映射到对应视觉 token，计算注意力落在问题相关区域的比例，并对推理后期赋予更高权重，防止模型"形式上看图、实际看错位置"骗取奖励。

三层奖励形成闭环：词汇奖励管证据有没有进入语言轨迹，记忆奖励管证据有没有贯穿推理前后，关键区域奖励管调用的是不是有效证据。它们与答案奖励共同进入 GRPO 训练——同一问题的多条 rollout 中，依据视觉证据推理的轨迹获得更高相对优势、逐渐占据更多策略概率。论文强调这不是传统损失函数中的 L1/L2/KL 正则项，而是**行为层面的奖励正则化**：不新增视觉知识，只通过提高视觉忠实轨迹的相对收益，缩小"可接受策略"的范围。训练集包含 38,657 个筛选样本，每个带视觉关键词与关键区域标注；这些标注不是为向模型灌输知识，而是为奖励函数提供过程锚点，用于识别"模型何时开始忘记、忘记了什么、注意力偏向哪里"。

### 为什么多模态后训练会发生分布性视觉遗忘

文章把遗忘归因于三个结构性因素的叠加，而非静态训练集单独造成：

1. **模态分布不对称**：自回归多模态模型中，视觉条件在生成开始时已固定，语言状态却随推理持续增长——视觉证据是固定条件，语言状态是增长变量，模型越往后越容易被自己生成的文本重新定义上下文。
2. **信用分配稀疏**：只奖励最终答案的结果监督，难以定位视觉依赖从哪一步开始衰减。
3. **正确轨迹不唯一**：同一答案背后，可能对应"每一步都重新调用图像"与"中途脱离图像、靠语言先验碰巧答对"两条完全不同的证据路径。

三者叠加构成典型的**轨迹不可辨识问题**：结果监督知道终点是否正确，却不知道模型为什么到达终点。当这种不可辨识性与长序列自回归累积叠加，遗忘就不再是偶发错误——每轮 rollout 都可能产生一批"碰巧答对但已经不看图"的轨迹，它们继续获得正向优势，策略逐步提高其生成概率。最终被强化的不只是某个答案，而是一种越来越偏向文本自洽、越来越远离视觉证据的推理分布。需要注意，这与监督学习意义上的 [[concepts/catastrophic-forgetting]] 不同：它不是旧任务知识被新任务覆盖，而是同一任务内部"依据观测"的行为模式被"依据自身叙事"的行为模式逐步挤出概率质量。

### 7B 模型七项基准全线提升的机制

过程奖励并不注入新的视觉知识，因此提升的来源是**重新组织模型调用既有视觉能力的方式**。相关注意力读取机制建立在标准 [[concepts/attention-mechanism]] 之上，无需改动模型结构。实验覆盖数学与逻辑推理、综合多模态能力、视觉感知三类任务，Remember-R1-7B 在七项基准上均高于基座模型，其中：

- MathVista 从 62.30 提升至 69.80（+7.50 分）；
- MMVet 从 59.44 提升至 72.37（+12.93 分）；
- RealWorldQA 从 69.28 提升至 69.67，基础视觉感知能力没有因过程约束而下降。

前两项说明过程奖励的收益并未局限在单一推理任务上；RealWorldQA 的持平则说明提升不是以牺牲"看见"换取"推理"。机制层面的解释是：过程奖励为"正确"增加了**证据条件**，让原本能获得相同结果奖励的多条轨迹在策略更新中被重新排序——视觉忠实轨迹被上调，脱离观测的语言捷径被下调，长链推理向纯文本分布漂移的倾向被显著抑制。

### 实验证据的边界

论文自陈的边界值得记录：这组实验证明的是所覆盖模型与基准上的有效性，并不等于视觉遗忘已被彻底消除；更准确的说法是三种过程奖励显著降低了长链推理向纯文本分布漂移的倾向。方法本身也面临过度正则化的风险——模型可能为反复提及图像而生成冗余描述，或因注意力被强行拉回视觉 token 而损害原有推理与感知能力，RealWorldQA 的持平结果是这一风险的初步回应而非完全排除。

## 实践启示

1. **把"遗忘"前移到后训练处理，而不是在推理阶段补救。** 重新插入原图、增加视觉声明与验证步骤解决的是"忘了之后再看一次"；在奖励函数里直接压低会忘记图像的轨迹，从源头减少这类策略被强化的概率。
2. **当结果奖励无法唯一确定正确行为时，先问"模型究竟会学到哪一种策略"。** 任何只看终点的 RL 训练都存在轨迹不可辨识问题；应主动审计 rollout 中"碰巧答对但证据失真"轨迹的占比，而不是等基准分数异常后再排查。
3. **过程奖励需同时覆盖语义、时间、空间三个维度才能防 reward hacking。** 只要求"说出视觉词"可被形式化应付（开头描述一次后全程不提）；必须叠加注意力保持（看了多久）与关键区域命中（看对了没有）作为交叉校验，单层约束都会留下可钻的空子。
4. **数据标注可以为奖励函数服务，而不只是为模型服务。** 38,657 个样本的关键词/区域标注不用于灌输知识，而用作过程锚点；这种"标注 → 奖励锚点"的思路可迁移到任何需要约束中间行为（而非只看最终输出）的后训练场景。
5. **后训练塑造的不只是能力上限，还有能力的调用策略。** 模型具备视觉感知能力 ≠ 会在长链推理中持续使用它；只有当"持续依据证据"进入奖励函数，策略优化才会把它变成高概率行为。这对 SFT/RL 阶段的目标设计（参见 Chap 06 Training Stages）与评测设计（参见 [[concepts/evaluation-harness-design]]）同样适用。
6. **凡是"外部观测固定/稀疏 + 内部语言状态持续增长"的任务结构，都可套用这一范式。** 长视频理解（早期帧被后续文本摘要覆盖）、屏幕操作 agent（逐渐相信自己的动作描述而非最新界面状态）、机器人导航（内部计划压过实时环境反馈）均属此类；与其等遗忘后增加检索、回看或验证，不如在后训练阶段直接奖励"持续依据环境"的轨迹——前提是能把证据表达、记忆保持和关键区域注意力转化为可计算信号。
