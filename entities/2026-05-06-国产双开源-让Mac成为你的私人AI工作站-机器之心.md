## 摘要

文章以 Ollama 2026 年 3 月底宣布 Mac 版底层推理引擎从 llama.cpp 切换为苹果 MLX 框架为引子（M5 芯片上 prefill 提速超 57%、生成速度接近翻倍、TTFT 最短缩至原来四分之一），指出 MLX 现有 W4A16/W8A16 量化只压权重、激活值仍跑 FP16，Apple GPU 里的 Neural Accelerator 硬件没被完整调用。明略科技为此开源两个项目：Cider（构建于 MLX 之上的端侧推理加速框架）提供 MLX 原生缺失的 W8A8/W4A8 激活量化模式，以融合算子把量化、矩阵乘法、反量化合并为一次 GPU 调度，借 Metal 4 TensorOps API 直用专用硬件——10240×2560 矩阵单算子测试较 MLX W8A16 提速 1.82~1.86 倍，Qwen3-VL-2B 端到端 prefill 加速约 57%~61%，Qwen3-8B 量化后 PPL 9.756 与 FP16 的 9.726 仅差 0.03 而 prefill 耗时从 179.9 秒降至 123.5 秒。Cider 的加速仅作用于 prefill 阶段，decode 自动回落原始权重、切换零开销。^[raw/articles/2026-05-06-国产双开源-让Mac成为你的私人AI工作站-机器之心.md]

另一个开源项目 Mano-P 1.0 是 GUI-VLA 智能体模型（Apache 2.0 协议），通过纯视觉理解直接看懂屏幕并操作 GUI，不依赖 CDP 协议或 HTML 解析：OSWorld 基准上 72B 版以 58.2% 成功率位列专用 GUI 智能体全球第一（领先第二名逾 13 个百分点），WebRetriever Protocol I 上以 41.7 分超过 Gemini 2.5 Pro Computer Use（40.9）和 Claude 4.5 Computer Use（31.3）；4B 量化模型在 M4 Pro 上 476 tokens/s prefill、76 tokens/s 解码、峰值内存 4.3GB，一台 32GB 内存 Mac mini 即可本地运行、截图数据不出设备。两者组合指向 Private AI 理念（"数据私有、推理私有、能力私有"）：在全自动编程流水线中 Mano-P 接替 GUI 测试环节（该环节云端 token 占比超 50%）直接归零云端开销，"构建-测试-修复"闭环完全本地执行。文章还披露下一个技术方向 Auto Agent Learning——让本地小模型用自然语言把密码等信息训练进权重而非存为明文，实现"你问它密码它说不知道，让它登录它却能做到"。^[raw/articles/2026-05-06-国产双开源-让Mac成为你的私人AI工作站-机器之心.md]

## 关键要点

- 从 M5 芯片起，苹果在每个 GPU 核心里嵌入矩阵乘法单元 Neural Accelerator，通过 Metal 4 的 TensorOps API 调用，这是苹果首次在 GPU 层提供可编程 AI 推理专用加速。
- W8A8/W4A8 激活量化目前仅在 Apple M5 Pro 上稳定支持，M1-M4 不支持；官方建议内存余量超出模型体积 4GB 以上的设备（32GB 及以上）使用 W8A8，否则可能因换页抵消加速收益。
- Cider 内置实验性 ANE+GPU 异构并行模块：prefill 阶段线性层按输出维度拆分，ANE 负责约 65% 通道、GPU 负责其余 35%，M4 上 Qwen3-VL-2B prefill 提速约 3%~17%。
- 在含 100 条任务（区分无 bug 与预注入 bug 版本）的 CUA 基准上，MacBook Pro M5 16GB 内存下 Mano-P 的 W8A16 准确率 58.0%、接入 Cider 的 W8A8 为 54.0%。
- Mano-AFK 流水线演示：一句自然语言需求出发自主完成需求澄清、架构设计、代码生成、本地部署，E2E 测试调用 Cider 加速的本地 Mano-P 驱动真实浏览器完成 GUI 自动化测试。
