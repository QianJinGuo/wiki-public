# Being-H0.8：50万小时视频训出的首个隐式触觉世界—动作模型

## 核心：把触觉放进"预测—执行—反馈"完整链路

Being-H0.8 是一套带触觉的隐式世界—动作模型：**预训练阶段**就教会机器人提前判断将要怎样接触物体，并在真正接触后根据触觉反馈及时调整动作。相比过去根据画面决定动作的世界模型，Being-H0.8 把触觉放进了完整链路——模型先根据当前画面预判接下来可能发生的接触，执行过程中再读取最新触觉，重新生成下一小段动作。^[raw/articles/世界模型有触觉了50万小时视频训出首个隐式触觉世界动作模型.md]

## 数据—模型—控制三层设计

- **数据层**：汇总数十家合作伙伴数据，建立超 50 万小时原始数据池，形成高质量数据集 UniHand-3.0，并通过 TactoHand 生成接触和邻近度标注。
- **模型层**：预训练时把动作执行后实际记录的视觉和触觉结果作为监督，让模型学习仅凭当前指令和画面提前判断接下来会怎样接触。
- **控制层**：每个动作块开始时先生成完整动作计划；每执行一小段，就读取最新机器人状态和触觉，只重算下一小段动作。

基于这套方法，Being-H0.8 在真实双臂机器人实验中完成了包中取物、毛笔写字、挤牙膏、夹薯片等依赖触觉的高难度精巧任务。^[raw/articles/世界模型有触觉了50万小时视频训出首个隐式触觉世界动作模型.md]

## 意义：触觉如何进入世界模型仍是开放问题

对于具身模型，触觉不仅关系到精细操作，还能帮助完成仅凭视觉难以实现的接触推断。李飞飞、徐丹飞、Wenzhen Yuan、宋舒然等研究者都在推进相关方向，但聚焦到世界模型层面，"触觉如何进入世界模型"仍是开放问题——Being-H0.8 首次用人类视频数据给出了一条可扩展路径。^[raw/articles/世界模型有触觉了50万小时视频训出首个隐式触觉世界动作模型.md]

## 深度分析

### 触觉如何隐式进入"预测—执行—反馈"循环

Being-H0.8 的关键设计取舍是：不在像素层面完整重建未来画面，而是在隐空间中预测交互后果。这使得触觉无需以"渲染出未来画面里的形变细节"这种昂贵方式进入模型，而是作为隐状态的一部分参与预测——与 [[entities/feifei-li-masked-visual-actions-world-model-2026|李飞飞 Masked Visual Actions 世界模型]] 同属"在隐空间/动作空间预测后果"的世界—动作模型路线。架构上由四个模块协同：Mixture of Transformers (MoT) 负责预测交互后果，通用触觉编码器把不同传感器的信号统一成触觉 token，慢—快动作专家兼顾推理效率与接触反馈，TopoHand 负责跨本体动作对齐。训练时，未来时刻的触觉 token 进入 MoT 的后验分支，让模型理解真实接触发生后世界状态应如何变化；部署时，MoT 提前预测交互后果，慢速流缓存视觉、语言和隐世界状态以维持整体任务上下文，快速流在动作执行中读取最新触觉、只重新生成下一小段动作。由此触觉不再只是动作完成后的附加反馈，而是同时进入了预测、执行与调整三个环节——这正是"隐式"的含义：模型从没有显式触觉标注的视频中学到了接触规律。

### 数据—模型—控制三层的具体分工

数据层解决"触觉从哪里来、如何统一"：以 50 万小时第一人称视频为底座，经 TactoHand 从普通视频恢复接触位置与邻近关系、压力手套补充真实物理压力、通用触觉编码器统一 token 格式、TopoHand 对齐人手/灵巧手/夹爪动作空间，四步流水线把无触觉记录的视频转化为可训练的触觉数据。模型层解决"学什么"：预训练时把动作执行后实际记录到的视觉和触觉结果作为监督，让模型仅凭当前指令和画面提前判断接下来会怎样接触。控制层解决"怎么用"：每个动作块开始时先生成完整动作计划，每执行一小段就读取最新机器人状态和触觉、只重算下一小段，避免每次触觉变化都重算完整计划。三层各自的难点不同——数据层难在异构统一，模型层难在隐空间监督信号设计，控制层难在实时性——这种分层拆解本身就值得同类系统借鉴。

### 50 万小时视频预训练到底贡献了什么

首先要澄清：50 万小时原始视频并不等于 50 万小时可训练数据。其中混有看不到手、缺少有效操作、镜头剧烈抖动、与桌面交互无关或高度重复的片段，且不同数据源在场景、任务、视角和动作分布上差异明显。这与 [[entities/rhoda-scaling-web-video-pretraining-robots|Rhoda 网络视频预训练路线]] 面对的"海量原始视频需重加工"问题同构。团队为此搭建了面向数十万小时视频的处理管线，做过滤、去重、切分、语言标注和分布再平衡；对人类视频用 MANO 统一手部表示、经 HMR 恢复细化手部运动轨迹（相关方向另见 [[entities/video-world-model-hand-motion-capture-2026|视频手部动作捕捉]]）、用 Caliball 补齐相机参数，对机器人数据则统一 URDF、关节约定和坐标系。视频预训练路线的真正贡献有三：其一，覆盖自然物体交互、长时程任务、丰富手部动作与多样场景的大规模人类交互经验；其二，通过 TactoHand（以 21 个人—物交互数据源、3010 万帧训练，在 MANO 的 778 个顶点上预测接触与邻近度）把"没有触觉标注"变成"可以学触觉"；其三，约 55 小时、540 万同步帧的压力手套数据作为真实物理信号锚点，与大规模视频形成"广度+精度"互补。从 Being-H0 到 H0.8 的三阶段演进——验证人类视频能不能用、解决怎么规模化用、再到怎么高质量用——说明这条路线的重心已从数据量转向单位数据提取的物理经验密度。

### 开放问题与路线局限

文章明确承认，触觉如何进入世界模型仍是开放问题。现有世界模型大多以视觉为核心，可以看到物体移动和形变却难以准确推断接触；触觉传感器种类繁多但数据形态与表征方式不统一，且绝大多数机器人并不配备触觉传感器。隐式路线的局限也随之而来：从视觉几何推断的接触无法完整获得压力、摩擦、剪切力、滑移和材质等物理信息，深度物理信号仍依赖真实传感器（当前仅 55 小时），隐式触觉的精度上限在哪里尚无答案；有效性标记虽区分了"没有传感器"与"压力读数为零"，但跨模态缺失下的训练稳定性、隐式监督与真实触觉的分布差异如何弥合，文章未展开。与之对照，显式触觉传感路线（如 [[entities/vision-based-tactile-sensor-overrated-critique-2026|视觉触觉传感器批判]] 一文所讨论的传感器形态）与隐式路线孰优孰劣，是接下来值得跟踪的分歧点；灵巧操作侧的并行探索可参看 [[entities/motus-2-self-evolving-world-model-dexterous-manipulation-2026|Motus-2 自进化灵巧操作世界模型]]。而 MoT 后验分支在部署时不再有"未来触觉"可用、只能靠预测，这一训练—部署不对称也是隐式方法的固有张力。

## 实践启示

1. **数据管线投入应先于模型规模扩张**：50 万小时原始视频须经过滤、去重、切分、标注、再平衡才能入训，管线质量决定模型上限——具身团队应把工程预算优先投向数据处理而非盲目堆数据。
2. **用几何先验替代昂贵的同步触觉采集**：TactoHand 证明借助手—物三维几何关系加时序信息，可从普通人类视频中批量生成伪触觉监督，这是把"稀缺模态"变成"可扩展模态"的通用配方。
3. **小而精的真实传感器数据当"校准锚点"而非主数据**：55 小时压力手套对齐 50 万小时视频，用少量高保真信号校准大规模低保真推断，比两条路线各自堆量更划算。
4. **分层控制化解触觉实时性与推理成本的矛盾**：慢速流维持任务上下文、快速流只重算下一小段动作的设计，可推广到任何需要高频反馈闭环的具身系统（参见 [[concepts/embodied-intelligence-frontier|具身智能前沿]]），避免"一次反馈、全量重算"。
5. **触觉数据工程要保留有效性标记**：区分"通道缺失"与"读数为零"直接影响训练信号质量，任何多源传感数据统一时都应内建该字段。
6. **具身数据壁垒的定义正在改变**：智在无界的护城河已从"拥有多少视频"转向"收集—清洗—动作恢复—触觉标注—世界建模—控制"全链路整合能力，评估具身公司时应按此链路完整性而非数据吨位判断。
