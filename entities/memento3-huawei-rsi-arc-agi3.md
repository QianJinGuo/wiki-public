# Memento 3：华为 RSI 游戏智能体（ARC-AGI-3 通关）

## 系统概况

Memento 3 是华为诺亚方舟实验室联合 UCL 等团队提出的 AI 智能体系统，打通了 ARC-AGI-3 公开集的 **25 款游戏、183 个关卡**，以 Claude Opus 5 为底模，**全程不更新模型权重、不做游戏微调** → [[raw/articles/memento3-huawei-rsi-arc-agi3-2026-10-12|原文存档]]。 ^[raw/articles/memento3-huawei-rsi-arc-agi3-2026-10-12.md]

## 关键数字

- 人类完成同样关卡需 **17135 次操作**，Memento 3 只用 **7518 次——比人类少约 56%**，RHAE（Relative Human Action Efficiency）拿下满分 100
- 对比：同样的 Claude Opus 5 在 ARC Prize 官方标准框架下平均 RHAE 仅约 40.7——换一套智能体系统成绩提升 **59.3 分**
- Atari Pong：AI 自主摸索出控制策略后**不再向大模型请求推理**，连续三局 21:0

## 核心机制：Code-as-Model

系统边玩边给自己升级：自己上手玩、自己琢磨规则、自己写代码，玩错了反思修改。其核心是**迭代修正的规则手册 + 可执行世界模型**（Code-as-Model）——把学到的游戏规则沉淀为可执行的代码化模型，而非微调底模，与「从记忆到自进化 agent」的 RSI 路线一致。 ^[raw/articles/memento3-huawei-rsi-arc-agi3-2026-10-12.md]

## 与 Memento-Skills 的关系

Memento 3 是 Memento 系列的延续（前代 Memento-Skills 让 Agent 通过技能外部记忆持续进化），但本作的领域是**游戏型 RSI**（操作效率 + 规则自学习），与技能设计的侧重点不同，属同一自进化路线的两个分支。 ^[raw/articles/memento3-huawei-rsi-arc-agi3-2026-10-12.md]

## 深度分析

### 同一底模，59.3 分差距：智能体层才是真正的变量

Claude Opus 5 在 ARC Prize 官方框架下平均 RHAE 约 40.7，换成 Memento 3 这套系统后直接满分——模型没动，动的只是围绕模型的一圈工程设计。这说明任务失败时瓶颈往往不在模型能力本身，而在记忆、验证与规划循环的组织方式上。Memento 3 的答案是：不微调、不更新权重，把「学习」整体搬到模型外部，沉淀为可检查、可执行、可回滚的工件。[[concepts/agent-self-improvement-loops|Agent 自改进循环]]与[[entities/self-improvements-modern-agentic-systems-survey-arxiv-2607-13104|现代 Agentic 自改进综述]]都把这类「外部化工件承载进化」视为不动权重实现 RSI 的代表性路线。

### 规则未知的探索，比给定规则的解题更难

ARC-AGI-3 与前代的关键区别在于：不再出题解题，而是把智能体扔进规则未知的世界——规则要自己猜、目标要自己找、操作效果要自己试，后续关卡还可能推翻已总结的经验。人类同样会卡住（解谜游戏 tr87 十二名人类参与者只有六人通关），说明难点不在操作执行，而在从稀疏观察中归纳世界的因果结构。Memento 3 用「假设—写成代码—重放验证—修正」的循环来逼近这一归纳过程，本质上是把科学方法压缩进了智能体的探索策略：任何一条规则都要经过真实操作的复现检验才能留在手册里。

### Code-as-Model：让知识的正确性变得可证伪

Rulebook（Markdown 规则手册）与可执行世界模型（Python 代码）是一对互补结构：前者承载人类可读的经验陈述，后者把陈述转译成可运行的模拟器。关键在验证闭环——每次修改后系统重放历史操作、逐格对比 64×64 画面，复现误差就是「规则错了」的客观信号，对不上就继续改，tr87 一局迭代了 11 版。相比训练一个神经世界模型，这条符号化路线牺牲泛化性，换来三样东西：错误可检测（不靠模型自我感觉）、修改可回滚（团队直接用 Git 管理规则版本）、推演低成本（模拟器内试错不烧 token）。在 wa30 上并行的双世界模型（共享操作记录、各自推演不同规则假设）把操作次数从 899 压到 597、约降 34%，本质是把多假设并行验证引入了世界模型的构建过程。

### 成本转移与适用边界：RSI 不是免费的

「不训练模型」不等于便宜：探索、生成代码与逐格验证都压在开启 Extra-High 推理强度的底模上，token 与算力开销显著。Pong 案例还揭示了这套方法的生命周期结构——前期靠大模型归纳反弹规律并写成代码，策略成熟后程序完全脱离大模型独立运行（三局 21:0），学成阶段仅用约 9500 帧画面，远低于传统 RL 常见的数十万乃至上亿帧；而不用世界模型、只让大模型看画面决策的对照只有 -19 分，与随机操作的 -20.7 几乎无异。这更像「LLM 当教师、把策略编译成代码」的蒸馏结构，而非永久依赖。边界同样明确：实验集中在规则相对明确的游戏环境，能否迁移到规则含混、动态多变的现实场景尚未验证；与 [[entities/motus-2-self-evolving-world-model-dexterous-manipulation-2026|Motus-2 神经世界模型路线]]相比，Code-as-Model 适用面更窄，但每一步更可审计。

### 给 RSI 装上护栏：可审计的自我改进

递归自我改进常与失控风险并提，Memento 3 则展示了一种「有护栏的 RSI」：所有自我修改都落在两个可审查的工件（规则手册、可执行代码）上，每次修改经重放验证把关，Git 记录完整历史，任何一次「进化」都能定位到具体 diff 并回滚。这与 [[entities/rrsi-regularized-recursive-self-improvement-agent-harnesses|正则化 RSI 研究]]的方向一致——用外部约束而非模型自觉来约束自我改进。冻结底模权重本身也是一种安全属性：系统的能力变化始终由可检查的外部工件决定，而非不可解释的参数漂移；进化被限制在「改攻略」这一人类熟悉的工程动作里。

## 实践启示

1. **先改智能体层，再考虑换模型。** 同一底模换一套系统就提升 59.3 分：表现不达标时，优先迭代记忆、验证与规划循环，而不是追新模型或直接微调。
2. **领域知识要沉淀成「能跑的工件」，而非自由文本。** 规则写成可执行代码，用重放对比做自动验证，错误才有客观信号。写 skill 与记忆条目同理：能带验证脚本的，别只留散文——这正是[[entities/agent-self-evolution-skill-to-weights-taxonomy-aliexpress-2026|Skill-to-Weights 自进化分类]]中「外部化工件优先于动权重」的思路。
3. **给自进化系统配版本管理与回滚。** Memento 3 用 Git 记录每次规则与代码修改，改错可回看历史、随时恢复；skill 库与记忆库的每次变更同样应当可追溯、可还原，否则一次错误的自我修改可能污染全部后续进化。
4. **显式维护「未解之谜」清单。** Rulebook 不仅记已知规律，还记录哪些规则没搞明白，这把探索预算引向信息增益最大的位置；对照实验中仅保留规则手册一项就减少约 9% 操作、18% 执行轮次。
5. **学稳了就降级模型调用。** Pong 打熟后系统不再请求 LLM 推理照赢 21:0。生产 agent 中已稳定的子任务应固化为代码路径，把 token 留给真正需要推理的决策。
6. **不确定时并行多假设，而非押注单点。** 双世界模型各自推演不同规则假设再择优，wa30 操作次数降约 34%；决策类系统同样可以对同一现象维护多个候选解释并行验证，再用真实反馈淘汰。
