# EDV：Execute-Distill-Verify 框架 — 浙大大模型智能体进化新路径

> 浙江大学联合清华大学、西北工业大学、中国科学技术大学和上海交通大学发布 EDV（Execute-Distill-Verify）框架，通过多智能体分工协作打破单智能体自我确认陷阱，实现大模型智能体的可靠自我进化。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

## 核心问题：自我确认陷阱

大多数智能体经验学习遵循"单智能体闭环"模式：同一智能体既执行任务，也复盘结果。在开放世界、长周期任务中，这触发致命失效模式——**自我确认陷阱（Self-Confirmation Trap）**：逻辑自洽但实际错误的行动轨迹很难被执行者自我察觉，反而被判定为"成功经验"写入记忆，导致错误被反复放大、持续累积。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

## EDV 框架：三阶段协同

EDV 全称为 Execute-Distill-Verify，三阶段环环相扣，复刻了人类社会从个体实践到群体共识的认知沉淀过程。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

### 1. Execute 执行阶段：异构并行探索

搭建异构智能体池，每个智能体对应不同的基础模型和提示策略。每处理一个任务时，系统随机抽取多个智能体组成执行组，让它们独立与环境交互、并行生成各自行动轨迹。核心价值是用异构性带来视角多样性。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

### 2. Distill 蒸馏阶段：第三方对比提炼

不让执行者自己总结经验，而是指派独立的蒸馏智能体扮演"中立复盘者"角色。蒸馏智能体横向对比所有执行轨迹，聚焦不同轨迹的差异点，提炼出"场景-风险-行动"结构化逻辑的候选经验。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

### 3. Verify 验证阶段：共识表决机制

候选经验需经过最严格的共识验证关卡。验证组由参与执行的所有智能体组成，采用**默认拒绝**策略：
- **全体一致通过** → 写入**共享记忆库**，所有智能体可复用
- **部分认可** → 写入对应智能体的**私有记忆库**，仅自身可用
- **未通过** → 直接丢弃，绝不进入记忆系统

## 推理阶段配套设计

### 能力矩阵
持续记录不同智能体在各类任务上的表现，新任务到来时匹配最擅长处理的智能体。数据完全来自蒸馏阶段的统计结果，零额外开销。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

### 双层记忆体系
- 新任务先检索**共享记忆库**，调取通用可靠的共识经验（检索率 72.3%）
- 不足时再检索当前执行者的**私有记忆库**，补充个性化适配经验

## 实验验证

在三个主流长周期智能体基准测试上验证：^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

- **τ²-bench**：平均 Pass@1 达 86.6，比强基线 Router 高出 3.1 个点
- **Mind2Web**：跨任务、跨网站、跨领域三种泛化设置下保持领先
- **MMTB**：整体得分达 58.10，超越所有对比方法

### 记忆质量提升
人工评测（5 分制）显示：
- 事实正确性从 3.72 → 4.41
- 可执行性从 3.58 → 4.32
- 内容特异性从 3.64 → 4.27
- 幻觉/噪声从 1.21 → 0.63
- 复用潜在危害从 1.08 → 0.51

### 关键发现
- 注入 10%"错误但自洽"经验使基线 Pass@1 从 82.5 暴跌至 77.2，证明错误记忆破坏性
- 消融实验证实优势来自**异构执行、对比蒸馏、共识验证三者的协同效应**
- EDV 还能降低 24.5% 推理 token 消耗

## 深层启示

EDV 提出核心判断：健壮的智能体进化不取决于积累了多少经验，而取决于在经验进入记忆前是否经过了可靠的构建与检验。将多智能体协作从"协作解题"延伸到"协作进化"。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

## 深度分析

**异构验证为何能破自我确认偏差。** 自我确认陷阱的根源是"裁判与运动员同一"——执行者复盘自己的轨迹时，会被生成该轨迹时同样的推理路径与盲区遮蔽。EDV 的解法是把这三个角色在结构上拆开：异构池里不同基础模型、不同提示策略的智能体思维盲区互不重叠，A 模型踩过的坑 B 模型可能顺利避开；第三方蒸馏智能体不参与执行，横向对比多条轨迹的差异点而非复述某条最优路径，从机制上消解了执行者偏差。这与 [[concepts/multi-agent-systems|多智能体系统]] 中"用视角多样性换可靠性"的一般原理一致，但 EDV 把它用在了经验构建而非任务解题上。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

**人类制度的映射。** EDV 三阶段几乎逐项对应人类社会已被验证的知识质控制度：Execute 对应同行各自独立实验，Distill 对应同行评审中审稿人对比分析他人工作并提炼可复用结论，Verify 的"全体一致→共享 / 部分认可→私有 / 未通过→丢弃"表决对应学术共识的形成与机构化的把关（编辑终审、标准委员会）。默认拒绝策略尤其接近司法与安全工程中的"证明责任前置"：未经检验的经验不享有"可复用"的推定资格。共同规律是——可靠性不来自任何单点的聪明，而来自角色分离带来的结构性制衡。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

**单智能体闭环 vs 第三方蒸馏的量化差距。** 消融实验给出了清晰的阶梯：单智能体自我验证几乎没有提升甚至略有下降（自己查自己的错本来就查不出）；单智能体加外部验证提升有限（只有一条轨迹，旁观者也难发现深层问题）；多智能体加第三方蒸馏有明显提升；再加共识验证达到最优。记忆污染实验则量化了闭环的代价——注入 10%"错误但自洽"经验使基线 Pass@1 从 82.5 跌至 77.2，错误经验以约 5.3 分的幅度系统性污染下游表现；而 EDV 的把关使人工评测中幻觉/噪声从 1.21 降至 0.63、复用潜在危害从 1.08 降至 0.51，事实正确性 3.72→4.41。验证环节的边际收益随验证多样性单调递增，这正是 [[concepts/agent-self-improvement-loops|自我改进回路]] 设计中"检查器独立性与强度"决定上限的直接证据。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]

**与 Harness Engineering 的关系：Verify 作为记忆准入的门禁。** 从 [[concepts/harness-engineering-framework|Harness Engineering]] 的视角看，Verify 阶段本质上是一个安装在"经验 → 长期记忆"写入路径上的确定性门禁（gate）：它不负责生成，只负责拒绝。这与 [[concepts/agent-memory-architecture|Agent Memory Architecture]] 中"写入端质量决定记忆系统上限"的结论互相印证——记忆系统的失效几乎都发生在入口，事后修剪的成本远高于准入把关。EDV 的局限同样以 harness 语言可解释：当所有异构智能体共享同一错误模式时，共识门禁失效（验证集与执行集同分布）；表现过差的智能体会干扰共识达成；多角色交互使错误归因复杂化——门禁的覆盖面取决于验证者与执行者错误的独立程度。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]（此段后半为基于原文局限性的推断分析）

## 实践启示

**个人 Agent 记忆系统可借鉴的三段式改造。** 单人使用 Hermes/Claude 类带记忆的 agent 时，最常见的污染正是自我确认陷阱：agent 把一次侥幸成功总结成规则写入 memory，此后反复复用。低成本仿照 EDV 的做法：(1) 写入前让另一份独立上下文（不同模型或清空对话的新会话）对"这条经验是否被证据支持"做第三方蒸馏而非让当事 agent 自评；(2) 定期用"反例质询"做 verify——追问该经验在哪些场景会失败，答不出失败条件的经验降级为待验证；(3) 记忆分两层，跨任务共识性经验与个人化偏好经验分开存放、分开检索，对应 EDV 的共享/私有记忆库与 72.3%/约三成的检索分层。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]（分层结构源自原文，具体操作流程为推断）

**异构池何时值得付出成本。** EDV 的三阶段可离线运行且天然并行，不增加线上推理调度开销，反而因高质量记忆减少试错使推理 token 消耗降低 24.5%——即异构的成本在离线侧，收益在在线侧。值得上异构池的信号：任务开放且无标准答案、错误后果会随复用累积（长周期记忆写入）、单模型在该任务族上有已知盲区。不值得的场景：任务有确定性判分（此时用判分器代替共识表决更便宜）、经验生命周期极短（错误来不及累积就被覆盖）、调用预算不允许每任务多轨迹并行。核心权衡是"验证多样性收益 vs 多倍执行成本"，与 [[concepts/agent-memory-lifecycle-philosophies|记忆生命周期]] 中"写入成本应与复用次数成正比"的原则一致。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]（成本结构来自原文，场景清单为推断）

**经验写入长期记忆的门禁清单。** 参考 EDV 的默认拒绝策略，任何经验写入长期记忆前可先过四道关：① 证据关——该经验是否来自可对比的多条轨迹而非单次执行；② 独立审关——是否由未参与执行的上下文审核过，审核者与执行者是否可能共享同一盲区；③ 表态关——全体通过才进共享层、部分通过只进私有层、存疑即丢弃，不做"先写入再观察"的乐观写入；④ 结构关——经验是否具备"场景-风险-行动"的具体结构，空泛的"仔细操作"式总结一律拒收。这套清单与 [[concepts/memory-consolidation-decay|记忆巩固与衰减]] 中的准入—巩固分离思路相通：宁可记忆少而准，不可多而脏。^[raw/articles/跳出自我确认陷阱浙大发布edv框架开启大模型智能体进化新路径.md]（门禁清单为基于原文三阶段机制的工程化推断）
