# AI能接管实验室了？中国科大最新研究给出真实物理世界的压力测试

> WeChat-新智元 | 发布于 2026-08-06 | 评分入库 v×c≥49

## 核心内容

新智元 2026-08-06 12:21 北京 新智元报道 我们如何判断人工智能是否已经足够聪明，能够从事科学研究，实现端到端的自主科学发现？ 中国科学技术大学发布的最新研究让AI「大脑」接管机器科学家实验室「身体」， 由此将这一问题从知识问答和方案生成，推进到真实物理世界中的实验执行与反馈学习。 论文链接：<https://arxiv.org/abs/2607.23045 研究团队搭建了一个机器催化实验室，其中包括45个覆盖合成、表征和催化性能测试的模块化自动工作站。 为了让AI理解和调用实验室能力，研究团队将这些能力封装为机器可读技能（skills）。AI智能体可以通过这些技能直接调用实验设备，同时接受真实设备能力、操作规范和实验条件的约束。 图1.用于催化研究的AI读得懂的机器科学家实验室架构。 图2.从科学意图到机器实验室执行路径。 压力测试 基于该平台，研究团队对由6种智能体框架和9种大语言模型构成的48种实际配置进行了系统评测。 测试覆盖32项由领域专家定义的研究任务，共计4,608次评测试次。评估不仅考察智能体能否生成实验计划，还追踪这些计划能否通过核验并下发至机器人系统，以及生成的工作流是否能够在无需人工干预的情况下直接执行。 残酷的真实世界评测结果 当前领先的大语言模型智能体距离「接管」仍有明显差距。在4,608次测试中，仅151个工作流无需人工修复即可执行，占全部测试的3.3%。表现最好的Claude Code与Claude Opus 4.7组合，可执行率为28.1%；Codex与GPT 5.5组合的可执行率为19.8%。 会调整参数，不等于会重新规划 研究。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md]

## 深度分析

### 「会写计划」与「会执行实验」之间隔着一整个物理世界

这项研究最有冲击力的不是某个模型的具体分数，而是评估维度的转换：它不问"AI 能否生成一份像样的实验方案"，而是追踪方案能否通过核验、下发到机器人系统、并在无人工干预的情况下直接执行^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:36-38]。在 6 种智能体框架 × 9 种大语言模型构成的 48 种实际配置、32 项专家定义任务、共 4,608 次评测试次中，只有 151 个工作流（3.3%）无需人工修复即可执行；表现最好的 Claude Code + Claude Opus 4.7 组合可执行率 28.1%，Codex + GPT 5.5 为 19.8%^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:42]。这说明以语言流畅度为主的纸面评估系统性高估了智能体的真实科研能力——一旦引入设备能力、操作规范等物理约束，可执行率就会断崖式下跌。

### 机器可读技能是物理世界的 harness

平台把 45 个覆盖合成、表征与催化性能测试的模块化自动工作站封装为机器可读技能（skills），智能体通过技能直接调用设备，同时被真实设备能力、操作规范和实验条件约束^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:26-28]。这与软件侧的 [[concepts/harness-engineering-framework]] 完全同构：技能层就是物理世界的工具接口，而它的约束比 API 更硬——参数错误不是报错重试，而是毁掉一批样品。技能封装的完备度直接决定智能体的能力上限，该平台本身可视为 [[concepts/agent-evaluation-benchmark-frameworks]] 在真实物理场景中的延伸。

### 参数微调 ≠ 科学层面的重新规划

把 Codex/GPT 5.5 置于五轮"规划—机器人执行—证据获取—重新规划"闭环后，智能体能根据返回的实验结果调整材料配方和操作条件，但调整始终停留在局部参数优化：五轮下来工作流骨架原封不动，没有重新设计分析方法，也没能纠正持续存在的关键遗漏（缺少电极黏结剂、缺少针对特定分析物的显色试剂）^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:46-52]。研究由此点出关键区分：读取反馈并调参，不等于识别出研究策略本身的问题。这暴露的是元认知层面的缺口——智能体缺乏质疑自身方案框架的能力，与 [[concepts/agent-self-improvement-loops]] 讨论的"从执行反馈上升到策略修正"是同一堵墙。

### 长程一致性瓶颈与「测试场→训练场」的双重定位

部分智能体能生成经专家评估可执行、最多包含 44 个操作步骤的工作流，但全部测试中只有 3 个工作流超过 30 步——任务链条一长，维持实验逻辑完整性和物理可执行性的能力就显著退化^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:56-58]。更重要的是平台的定位：机器实验室既是检验 AI 科学能力的"测试场"，也可以是推动 AI 持续进化的"训练场"——成功的工作流、失败案例、实验结果和专家评估都能沉淀为模型训练与智能体对齐的数据，驱动"规划—执行—反馈—重新规划"闭环持续迭代^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:68-70]。这把"AI 是否足够聪明来做科学"从不可验证的争论，变成了可量化、可重复、可验证的物理世界证据。

## 实践启示

1. 评估科研或工程类智能体时，把"无人工修复可执行率"作为硬指标，而不是只看方案生成的质量分——3.3% 与 28.1% 之间的巨大方差说明，同一批模型换个执行口径，结论会完全不同^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:42]。
2. 让 agent 接入真实业务前，先把领域能力封装成带约束的机器可读技能：技能描述要包含能力边界、操作规范和前置条件，而不只是调用签名，否则 agent 只能"看起来会用"。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:26-28]
3. 设计闭环反馈时，不能只让 agent "读结果、调参数"——那会把系统锁死在局部优化盆地；每轮迭代应强制要求对工作流骨架本身提出质疑或给出替代方案。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:46-52]
4. 长程任务要控制在模型能维持逻辑完整性的步数范围内（该研究中超过 30 步的工作流几乎全军覆没），超长链条应插入外部校验点，分段核验后再下发执行。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:56-58]
5. 人工修复记录是比成功案例更值钱的资产：像"训练场"模式那样，把每次人工干预的原因、位置和修正方式沉淀为结构化数据，用于持续迭代模型与智能体系统。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:68-70]
6. 引入"AI 科学家"时逐级验收三种经常被混为一谈的能力——流畅生成实验计划、生成可物理执行的工作流、根据结果调整整体研究策略——不要用单一指标笼统下结论。^[raw/articles/ai能接管实验室了中国科大最新研究给出真实物理世界的压力测试.md:62-64]
