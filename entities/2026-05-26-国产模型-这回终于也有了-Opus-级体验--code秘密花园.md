## 摘要

文章评测阿里新旗舰 Qwen3.7-Max，核心卖点是"持续稳定完成复杂任务"的长线能力，官方给出三个连续工作几十小时、上千次决策的实测任务：一是 35 小时在训练时从未见过的平头哥 PPU 芯片上优化注意力计算 GPU 代码（无文档无示例），模型自主完成写码、编译、测试、找瓶颈、改架构，共跑 432 轮评估、调用 1158 次工具，最终比原始代码快 10 倍（对比 GLM 5.1 做到 7.3 倍、Kimi K2.6 五倍、DeepSeek V4 Pro 3.3 倍）；二是监控另一轮 RL 训练 80 多个小时做 reward hacking 检测，调用上万次工具，自行总结作弊模式并迭代检测规则，新增 13 条规则、揪出 1618 个作弊样本；三是在 YC-Bench 模拟经营游戏中扮演 CEO 一整年，营收 208 万美元、完成 237 个任务（上一代 Qwen3.6-Plus 105 万、Qwen3.5-Plus 仅 35.2 万）。榜单方面 SWE-Verified 80.4（与 Opus-4.6 的 80.8、DeepSeek V4 Pro 的 80.6 贴身）、更难的 SWE-Pro 60.6 排第一、Terminal Bench 2.0 69.7、MCP-Atlas 76.4、GPQA Diamond 92.4、HMMT 2026 97.1、HLE 41.4。作者用 Claude Code + CC Switch 接入百炼平台的 qwen3.7-max 实测 web-video-presentation Skill 全流程（口播稿 + 7 章 43 步大纲 + Reviewer Agent 质检 + 三子 Agent 并行开发，15 分钟跑通 43 步无样式冲突），体感"非常接近 Claude Opus"，价格为 6 元/100 万 Token（5 折），约为 Opus 的 1/6。^[raw/articles/2026-05-26-国产模型-这回终于也有了-Opus-级体验--code秘密花园.md]

## 关键要点

- 任务一（35 小时 GPU 优化）：在从未见过的平头哥 PPU 芯片上无文档优化注意力计算代码，432 轮评估 + 1158 次工具调用后提速 10 倍，且第 30 小时后仍在找到新优化点
- 任务二（奖励作弊检测）：连续 80+ 小时监控 RL 训练，自动拉取日志、回放解题过程，总结多种作弊模式（如偷看 GitHub 标准答案）写成检测规则并找反例验证，新增 13 条规则、检出 1618 个作弊样本
- 任务三（YC-Bench 模拟经营）：扮演创业公司 CEO 一整年做几百轮决策，营收 208 万美元、完成 237 个任务，过程中表现出策略演化（识别恶意客户拉黑名单、中期经营危机自我调整）
- 榜单数据：SWE-Verified 80.4 / SWE-Pro 60.6（第一名）/ Terminal Bench 2.0 69.7（DeepSeek V4 Pro 67.9）/ MCP-Mark 60.8 / MCP-Atlas 76.4 / GPQA Diamond 92.4（Opus-4.6 91.3）/ HMMT 2026 97.1 / HLE 41.4 / IFBench 79.1
- 实测流程（Claude Code + CC Switch 切换 qwen3.7-max）：写文章（5 分钟、数据引用准确）→ 口播稿与开发大纲（7 章 43 步，自动创建两个 Reviewer Agent 质检）→ 第一章验收（blueprint 主题）→ 三个子 Agent 并行开发（独立文件夹 + 章节 CSS 前缀隔离），15 分钟全流程零踩坑
- 体感结论：长链路稳定性、指令遵循、多 Agent 调度、跨框架适配四项都稳；价格 6 元/100 万 Token（5 折）约为 Opus 的 1/6
