# Seedance 2.5 vs MiniMax H3：国产 AI 视频模型对比

2026 年 7 月底，Seedance 2.5 和 MiniMax H3 同期上线，视频生成领域再次活跃。

## Seedance 2.5

- 字节跳动旗下，已在即梦和豆包专业版全量上线
- API 服务尚未正式上线，预计一周后开放
- 价格信息已更新到火山方舟平台

## MiniMax H3

- MiniMax 最新视频生成模型
- 与 Seedance 2.5 同期发布

## 对比维度

- 生成质量（画面细节、一致性）
- 生成速度
- API 定价
- 可用性和集成度

## 行业趋势

国产 AI 视频模型竞争加剧，从单一模型能力比拼转向生态和价格竞争。
