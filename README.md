# LLM Wiki Public Mirror

这是 canonical wiki 的公开知识层镜像，供 [wiki-book](https://github.com/QianJinGuo/wiki-book) 的公开文章导航使用。

公开范围包括精选的 `entities/`、`concepts/`、`comparisons/`、`queries/` 和 `moc/` 页面。`raw/articles/` 只保留来源索引页和原始来源链接，不复制私有 wiki 中保存的原文正文、收件箱、运行状态或操作资料。

该仓库由私有 canonical wiki 的同步脚本生成；页面内容仍应遵守各自来源的版权和许可边界。公开链接规则由 wiki-book 根目录的 `site-links.json` 统一维护。
